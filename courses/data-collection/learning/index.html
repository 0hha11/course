详细的课程知识点和学习指南

课程概述

数据采集与处理课程是商务数据分析与应用专业的核心课程之一，旨在帮助学生掌握数据采集的方法和技术， 以及数据预处理和转换的技巧，为后续的数据分析和挖掘提供高质量的数据基础。

通过本课程的学习，学生将能够：

  • 掌握数据采集的基本概念和方法
  • 学习网络爬虫技术和工具
  • 掌握数据预处理和转换的技巧
  • 学习数据清洗和数据质量评估
  • 能够从多种数据源采集和处理数据

第1章：数据采集概述

1.1 数据采集的概念和重要性

数据采集是指从各种数据源获取数据的过程，是数据分析的第一步。高质量的数据采集是后续分析的基础。

数据采集的重要性：

  • 为数据分析提供原始数据
  • 确保数据的完整性和准确性
  • 支持业务决策和问题解决
  • 发现新的业务机会
  • 提高数据处理的效率

1.2 数据源的类型

常见的数据源类型：

  • 网页数据：网站、社交媒体、论坛等
  • 数据库：关系型数据库、NoSQL数据库等
  • API接口：第三方服务提供的API
  • 文件数据：CSV、Excel、JSON等格式的文件
  • 传感器数据：IoT设备、监控系统等
  • 日志数据：服务器日志、应用日志等

1.3 数据采集的应用场景

  • 市场调研：收集竞争对手信息、市场趋势等
  • 价格监控：跟踪电商平台的商品价格
  • 社交媒体分析：收集和分析社交平台数据
  • 新闻聚合：自动收集和整理新闻信息
  • 学术研究：收集研究数据和文献资料
  • 业务分析：收集企业内部和外部业务数据

第2章：网络爬虫基础

2.1 HTTP协议基础

HTTP（HyperText Transfer Protocol）是用于在Web上传输数据的协议，是爬虫与Web服务器通信的基础。

  • 请求方法：GET、POST、PUT、DELETE等
  • 请求头：User-Agent、Cookie、Referer等
  • 响应状态码：200（成功）、404（未找到）、500（服务器错误）等
  • 响应头：Content-Type、Set-Cookie等
  • 响应体：服务器返回的实际内容

2.2 HTML结构解析

HTML（HyperText Markup Language）是网页的标准标记语言，爬虫需要解析HTML结构来提取数据。 

<!DOCTYPE html>
<html>
<head>
    <title>示例网页</title>
</head>
<body>
    <div class="container">
        <h1>标题</h1>
        <p class="content">内容</p>
        <a href="https://example.com">链接</a>
    </div>
</body>
</html>

2.3 爬虫的工作原理和流程

  1. URL队列：存储待爬取的URL
  2. 发送请求：向服务器发送HTTP请求
  3. 获取响应：接收服务器返回的响应
  4. 解析内容：解析HTML或其他格式的内容
  5. 提取数据：从解析后的内容中提取需要的数据
  6. 存储数据：将提取的数据存储到本地或数据库
  7. 发现新URL：从当前页面中发现新的URL并加入队列
  8. 重复过程：继续爬取下一个URL

2.4 爬虫的合法性和道德规范

  • 遵守网站的robots.txt规则
  • 不要过度请求，避免对服务器造成压力
  • 尊重网站的版权和知识产权
  • 不要爬取敏感信息
  • 遵守相关法律法规

3.3 Scrapy框架的使用

Scrapy是一个功能强大的Python爬虫框架，提供了完整的爬虫解决方案。 

# 创建Scrapy项目
# scrapy startproject tutorial

# 创建爬虫
# scrapy genspider example example.com

# 爬虫代码示例
import scrapy

class ExampleSpider(scrapy.Spider):
    name = 'example'
    allowed_domains = ['example.com']
    start_urls = ['http://example.com/']

    def parse(self, response):
        # 提取数据
        title = response.css('h1::text').get()
        content = response.css('.content::text').get()
        
        #  yield数据
        yield {
            'title': title,
            'content': content
        }
        
        # 跟进链接
        next_page = response.css('a.next::attr(href)').get()
        if next_page:
            yield response.follow(next_page, self.parse)

# 运行爬虫
# scrapy crawl example

# 存储数据
# scrapy crawl example -o items.json

第5章：数据预处理

5.1 数据清洗

数据清洗是指处理数据中的错误、缺失值和异常值的过程。 

import pandas as pd
import numpy as np

# 创建示例数据
data = {
    'name': ['Tom', 'Jerry', 'Alice', 'Bob', None],
    'age': [18, 20, None, 25, 30],
    'city': ['Beijing', 'Shanghai', 'Guangzhou', 'Shenzhen', 'Beijing'],
    'salary': [5000, 6000, 7000, 8000, 9000]
}

df = pd.DataFrame(data)
print("原始数据:")
print(df)

# 处理缺失值
df['name'].fillna('Unknown', inplace=True)
df['age'].fillna(df['age'].mean(), inplace=True)

# 处理重复值
df.drop_duplicates(subset=['city'], keep='first', inplace=True)

# 处理异常值
# 假设salary的合理范围是4000-10000
df = df[(df['salary'] >= 4000) & (df['salary'] <= 10000)]

print("清洗后的数据:")
print(df)

第6章：数据质量评估

6.1 数据质量的维度

数据质量的主要维度：

  • 完整性：数据是否完整，是否有缺失值
  • 准确性：数据是否准确反映真实情况
  • 一致性：数据是否一致，是否有矛盾
  • 时效性：数据是否及时更新
  • 可靠性：数据来源是否可靠
  • 可访问性：数据是否易于访问和使用

6.2 数据质量评估方法

import pandas as pd
import numpy as np

# 创建示例数据
data = {
    'name': ['Tom', 'Jerry', 'Alice', 'Bob', None],
    'age': [18, 20, None, 25, 30],
    'city': ['Beijing', 'Shanghai', 'Guangzhou', 'Shenzhen', 'Beijing'],
    'salary': [5000, 6000, 7000, 8000, 9000]
}

df = pd.DataFrame(data)

# 评估完整性
missing_values = df.isnull().sum()
missing_percentage = (df.isnull().sum() / len(df)) * 100
print("缺失值情况:")
print(missing_values)
print("\n缺失值百分比:")
print(missing_percentage)

# 评估一致性
# 检查重复值
duplicate_rows = df.duplicated()
print("\n重复行:")
print(duplicate_rows.sum())

# 评估准确性
# 检查年龄是否合理
total_rows = len(df)
invalid_age = len(df[(df['age'] < 0) | (df['age'] > 120)])
print("\n无效年龄数量:", invalid_age)
print("年龄准确率:", (total_rows - invalid_age) / total_rows * 100, "%")

# 评估时效性
# 假设数据是2023年收集的，检查数据是否是2023年的
df['year'] = [2023, 2023, 2022, 2023, 2023]
outdated_data = len(df[df['year'] < 2023])
print("\n过时数据数量:", outdated_data)
print("数据时效性:", (total_rows - outdated_data) / total_rows * 100, "%")

第8章：案例分析

8.1 案例一：电商商品数据采集

采集电商平台的商品数据，包括商品名称、价格、评价等信息。 

import requests
from bs4 import BeautifulSoup
import csv

# 采集商品数据
def crawl_products(url):
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36'
    }
    
    response = requests.get(url, headers=headers)
    soup = BeautifulSoup(response.text, 'html.parser')
    
    products = []
    
    # 提取商品信息
    for item in soup.select('.product-item'):
        name = item.select_one('.product-name').text.strip()
        price = item.select_one('.product-price').text.strip()
        rating = item.select_one('.product-rating').text.strip()
        reviews = item.select_one('.product-reviews').text.strip()
        
        products.append({
            'name': name,
            'price': price,
            'rating': rating,
            'reviews': reviews
        })
    
    return products

# 主函数
def main():
    url = 'https://example.com/products'
    products = crawl_products(url)
    
    # 存储数据
    with open('products.csv', 'w', newline='', encoding='utf-8') as f:
        writer = csv.DictWriter(f, fieldnames=['name', 'price', 'rating', 'reviews'])
        writer.writeheader()
        writer.writerows(products)
    
    print(f"采集了{len(products)}个商品数据")

if __name__ == '__main__':
    main()

    url = f'https://api.socialmedia.com/users/{user_id}/posts'
    headers = {
        'Authorization': f'Bearer {api_key}',
        'Content-Type': 'application/json'
    }
    
    response = requests.get(url, headers=headers)
    
    if response.status_code == 200:
        data = response.json()
        return data['posts']
    else:
        print(f"请求失败: {response.status_code}")
        return []

8.3 案例三：新闻数据采集与分析

采集新闻网站的新闻数据，并进行简单的分析。 

import requests
from bs4 import BeautifulSoup
import pandas as pd
import matplotlib.pyplot as plt

# 采集新闻数据
def crawl_news(url):
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36'
    }
    
    response = requests.get(url, headers=headers)
    soup = BeautifulSoup(response.text, 'html.parser')
    
    news = []
    
    # 提取新闻信息
    for item in soup.select('.news-item'):
        title = item.select_one('.news-title').text.strip()
        content = item.select_one('.news-content').text.strip()
        date = item.select_one('.news-date').text.strip()
        category = item.select_one('.news-category').text.strip()
        
        news.append({
            'title': title,
            'content': content,
            'date': date,
            'category': category
        })
    
    return news

# 分析新闻数据
def analyze_news(news):
    df = pd.DataFrame(news)
    
    # 统计各分类的新闻数量
    category_counts = df['category'].value_counts()
    print("各分类新闻数量:")
    print(category_counts)
    
    # 绘制饼图
    plt.figure(figsize=(10, 6))
    category_counts.plot.pie(autopct='%1.1f%%')
    plt.title('新闻分类分布')
    plt.ylabel('')
    plt.savefig('news_category.png')
    plt.show()

# 主函数
def main():
    url = 'https://example.com/news'
    news = crawl_news(url)
    
    # 存储数据
    df = pd.DataFrame(news)
    df.to_csv('news.csv', index=False, encoding='utf-8')
    
    # 分析数据
    analyze_news(news)
    
    print(f"采集了{len(news)}条新闻数据")

if __name__ == '__main__':
    main()
