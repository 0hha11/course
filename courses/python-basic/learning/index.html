课程概述

Python基础课程是商务数据分析与应用专业的核心课程之一，旨在帮助学生掌握Python编程语言的基础语法和核心概念， 为后续的数据分析和数据处理课程打下坚实的基础。

第1章：Python简介

1.1 Python的历史和特点

Python由Guido van Rossum于1989年创建，1991年发布第一个版本。Python的设计理念是"优雅"、"明确"、"简单"。

Python的主要特点：

  • 简单易学：语法简洁，代码可读性高
  • 解释执行：不需要编译，直接运行
  • 面向对象：支持面向对象编程
  • 丰富的库：拥有大量的标准库和第三方库
  • 跨平台：可以在多种操作系统上运行

1.2 安装和配置Python环境

安装Python的步骤：

  1. 访问Python官方网站（https://www.python.org/）
  2. 下载适合自己操作系统的Python版本
  3. 运行安装程序，注意勾选"Add Python to PATH"
  4. 完成安装后，在命令行中输入python --version验证安装成功

1.3 第一个Python程序

创建并运行第一个Python程序： 

print("Hello, Python!")

运行方法：

  1. 创建一个名为hello.py的文件
  2. 在文件中输入上面的代码
  3. 在命令行中运行python hello.py
  4. 看到输出"Hello, Python!"

第2章：数据类型和运算符

2.1 基本数据类型

Python的基本数据类型包括：

  • 整数（int）：如 1, 2, 3, -4
  • 浮点数（float）：如 1.0, 2.5, -3.14
  • 字符串（str）：如 "Hello", 'Python'
  • 布尔值（bool）：True, False
  • 空值（None）：表示没有值

2.2 复合数据类型

Python的复合数据类型包括：

  • 列表（list）：可变的有序序列，如 [1, 2, 3, "hello"]
  • 元组（tuple）：不可变的有序序列，如 (1, 2, 3, "hello")
  • 字典（dict）：键值对的集合，如 {"name": "Tom", "age": 18}
  • 集合（set）：无序的唯一元素集合，如 {1, 2, 3, 4}

2.3 运算符

Python的运算符包括：

  • 算术运算符：+, -, *, /, //, %, **
  • 比较运算符：==, !=, >, <, >=, <=
  • 逻辑运算符：and, or, not
  • 赋值运算符：=, +=, -=, *=, /=, //=, %=, **=
  • 成员运算符：in, not in
  • 身份运算符：is, is not

第3章：控制结构

3.1 条件语句

if语句的基本结构： 

if 条件1:
    # 条件1为真时执行的代码
elif 条件2:
    # 条件2为真时执行的代码
else:
    # 所有条件都为假时执行的代码

3.2 循环语句

for循环： 

for 变量 in 可迭代对象:
    # 循环体

while循环： 

while 条件:
    # 循环体

3.3 循环控制语句

  • break：跳出当前循环
  • continue：跳过当前循环的剩余部分，进入下一次循环
  • pass：空语句，什么也不做

第4章：函数

4.1 函数的定义和调用

函数的定义： 

def 函数名(参数1, 参数2, ...):
    """函数文档字符串"""
    # 函数体
    return 返回值

函数的调用： 

函数名(参数1, 参数2, ...)

4.2 参数传递

  • 位置参数：按照参数的位置顺序传递
  • 关键字参数：使用参数名指定参数值
  • 默认参数：为参数设置默认值
  • 可变参数：*args（接收任意数量的位置参数）
  • 关键字可变参数：**kwargs（接收任意数量的关键字参数）

4.3 递归函数

递归函数是指在函数体内调用自身的函数。例如，计算阶乘： 

def factorial(n):
    if n == 1:
        return 1
    else:
        return n * factorial(n-1)

第5章：面向对象编程

5.1 类和对象

类的定义： 

class 类名:
    def __init__(self, 参数1, 参数2, ...):
        # 初始化方法
        self.属性1 = 参数1
        self.属性2 = 参数2
    
    def 方法名(self, 参数1, 参数2, ...):
        # 方法体
        return 返回值

创建对象： 

对象名 = 类名(参数1, 参数2, ...)

5.2 继承

继承是指一个类继承另一个类的属性和方法： 

class 父类:
    # 父类定义

class 子类(父类):
    # 子类定义，可以重写父类的方法

5.3 多态

多态是指不同类的对象对同一方法调用做出不同的响应： 

class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

# 多态示例
def animal_speak(animal):
    print(animal.speak())

dog = Dog()
cat = Cat()
animal_speak(dog)  # 输出: Woof!
animal_speak(cat)  # 输出: Meow!

第6章：文件操作

6.1 文件的打开和关闭

使用open()函数打开文件： 

# 打开文件
file = open("文件名", "模式")

# 操作文件

# 关闭文件
file.close()

使用with语句自动关闭文件： 

with open("文件名", "模式") as file:
    # 操作文件

6.2 文件的读取

  • read()：读取整个文件
  • readline()：读取一行
  • readlines()：读取所有行，返回列表

6.3 文件的写入

  • write()：写入字符串
  • writelines()：写入字符串列表

第7章：异常处理

7.1 异常的概念

异常是指程序运行过程中发生的错误，如除以零、访问不存在的文件等。

7.2 try-except语句

使用try-except语句捕获异常： 

try:
    # 可能引发异常的代码
except 异常类型1:
    # 处理异常类型1的代码
except 异常类型2:
    # 处理异常类型2的代码
except:
    # 处理其他异常的代码
finally:
    # 无论是否发生异常都会执行的代码

7.3 自定义异常

自定义异常类： 

class MyException(Exception):
    pass

# 引发自定义异常
raise MyException("自定义异常信息")

第8章：模块和包

8.1 模块的导入和使用

导入模块的方式： 

# 导入整个模块
import 模块名

# 导入模块中的特定函数
from 模块名 import 函数名

# 导入模块中的所有函数
from 模块名 import *

# 给模块起别名
import 模块名 as 别名

8.2 包的创建和管理

包是包含多个模块的目录，需要包含__init__.py文件：

  • 创建一个目录作为包
  • 在目录中创建__init__.py文件
  • 在目录中添加模块文件
  • 使用import语句导入包或包中的模块
