供应链数据分析学习内容

详细的课程知识点和学习指南

课程概述

供应链数据分析课程是商务数据分析与应用专业的核心课程之一，旨在帮助学生掌握供应链数据分析的方法和技术， 优化供应链流程，提高供应链效率和透明度，为企业供应链决策提供支持。

通过本课程的学习，学生将能够：

  • 掌握供应链管理的基本概念和流程
  • 学习供应链数据分析的方法和技术
  • 掌握供应链绩效评估指标和方法
  • 学习供应链优化策略和方法
  • 能够使用数据分析工具解决供应链问题

第1章：供应链管理概述

1.1 供应链的概念和结构

供应链是指从原材料采购到最终产品交付给消费者的整个过程中，涉及的所有活动、参与者和资源的网络。

  • 供应链的组成部分：供应商、制造商、分销商、零售商、消费者
  • 供应链的流程：采购、生产、物流、销售、售后服务
  • 供应链的类型：推式供应链、拉式供应链、推拉结合式供应链

1.2 供应链管理的重要性

供应链管理是指对供应链中的物流、信息流和资金流进行计划、组织、协调和控制的过程。

  • 降低运营成本
  • 提高客户满意度
  • 增强企业竞争力
  • 提高资源利用效率
  • 减少库存水平

1.3 供应链管理的挑战

  • 需求不确定性
  • 供应链复杂性
  • 信息不对称
  • 全球化挑战
  • 风险管理
  • 可持续发展要求

第2章：供应链数据来源

2.1 供应链数据的类型

  • 交易数据：订单、发票、付款记录等
  • 库存数据：库存水平、库存周转率、库存成本等
  • 物流数据：运输时间、运输成本、配送路线等
  • 生产数据：生产计划、生产进度、生产效率等
  • 供应商数据：供应商绩效、供应商风险、供应商能力等
  • 客户数据：客户需求、客户满意度、客户反馈等

2.2 供应链数据的来源

  • 企业内部系统：ERP、WMS、TMS、CRM等
  • 供应商系统：供应商管理系统、采购系统等
  • 第三方平台：电商平台、物流平台、供应链金融平台等
  • 物联网设备：RFID、传感器、GPS等
  • 外部数据源：市场数据、行业数据、宏观经济数据等

第3章：供应链绩效评估

3.1 供应链绩效指标体系

供应链绩效指标体系是评估供应链运作效率和效果的重要工具。

  • 财务指标：成本、利润、ROI等
  • 客户服务指标：交货时间、准时交货率、订单满足率等
  • 运营指标：库存周转率、生产效率、物流效率等
  • 质量指标：产品质量、退货率、缺陷率等
  • 可持续发展指标：碳排放、能源消耗、社会责任等

第4章：需求预测分析

4.1 需求预测的重要性

需求预测是供应链管理的重要组成部分，它影响着生产计划、库存管理、采购决策等多个环节。

  • 优化库存水平
  • 提高客户服务水平
  • 降低运营成本
  • 提高生产效率
  • 支持战略决策

4.2 需求预测方法

常见的需求预测方法：

  • 定性方法：专家意见法、德尔菲法、市场调研法等
  • 时间序列方法：移动平均法、指数平滑法、ARIMA模型等
  • 因果关系方法：回归分析、神经网络等
  • 组合方法：综合多种预测方法的结果

4.3 需求预测模型

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.holtwinters import ExponentialSmoothing
from sklearn.metrics import mean_absolute_error, mean_squared_error

# 生成示例需求数据
dates = pd.date_range('2023-01-01', '2023-12-01', freq='MS')
demand = [100, 120, 130, 150, 160, 180, 170, 190, 200, 220, 230, 250]
df = pd.DataFrame({'date': dates, 'demand': demand})
df.set_index('date', inplace=True)

# 分割训练集和测试集
train = df[:9]
test = df[9:]

# 拟合指数平滑模型
model = ExponentialSmoothing(train['demand'], trend='add', seasonal=None)
model_fit = model.fit()

# 预测
forecast = model_fit.forecast(len(test))

# 评估预测精度
mae = mean_absolute_error(test['demand'], forecast)
rmse = np.sqrt(mean_squared_error(test['demand'], forecast))
mape = np.mean(np.abs((test['demand'] - forecast) / test['demand'])) * 100

print(f"MAE: {mae:.2f}")
print(f"RMSE: {rmse:.2f}")
print(f"MAPE: {mape:.2f}%")

# 绘制预测结果
plt.figure(figsize=(12, 6))
plt.plot(train.index, train['demand'], label='训练数据')
plt.plot(test.index, test['demand'], label='实际需求')
plt.plot(test.index, forecast, label='预测需求')
plt.title('需求预测')
plt.xlabel('日期')
plt.ylabel('需求量')
plt.legend()
plt.savefig('demand_forecast.png')
plt.show()

4.4 预测精度评估

  • 平均绝对误差（MAE）：预测值与实际值之差的绝对值的平均值
  • 均方根误差（RMSE）：预测值与实际值之差的平方的平均值的平方根
  • 平均绝对百分比误差（MAPE）：预测值与实际值之差的绝对值与实际值的比率的平均值
  • R²值：模型解释实际数据变异的比例

第5章：库存优化分析

5.1 库存管理模型

常见的库存管理模型：

  • 经济订货批量（EOQ）模型：确定最优订货量，使总库存成本最小
  • 再订货点（ROP）模型：确定何时订货，考虑提前期和安全库存
  • ABC分类法：根据物品的重要性进行分类管理
  • 定期库存系统：定期检查库存并订货
  • 定量库存系统：当库存水平达到再订货点时订货

5.2 库存水平优化

import numpy as np
import matplotlib.pyplot as plt

# 经济订货批量（EOQ）模型
def calculate_eoq(annual_demand, ordering_cost, holding_cost):
    """计算经济订货批量"""
    eoq = np.sqrt((2 * annual_demand * ordering_cost) / holding_cost)
    return eoq

# 计算总库存成本
def calculate_total_cost(quantity, annual_demand, ordering_cost, holding_cost):
    """计算总库存成本"""
    ordering_cost_total = (annual_demand / quantity) * ordering_cost
    holding_cost_total = (quantity / 2) * holding_cost
    total_cost = ordering_cost_total + holding_cost_total
    return total_cost

# 参数设置
annual_demand = 10000  # 年需求量
ordering_cost = 50  # 每次订货成本
holding_cost = 2  # 单位年持有成本

# 计算EOQ
eoq = calculate_eoq(annual_demand, ordering_cost, holding_cost)
print(f"经济订货批量: {eoq:.2f}")

# 计算总库存成本
total_cost = calculate_total_cost(eoq, annual_demand, ordering_cost, holding_cost)
print(f"总库存成本: {total_cost:.2f}")

# 绘制成本曲线
quantities = np.arange(100, 1500, 50)
costs = [calculate_total_cost(q, annual_demand, ordering_cost, holding_cost) for q in quantities]

plt.figure(figsize=(12, 6))
plt.plot(quantities, costs)
plt.axvline(x=eoq, color='r', linestyle='--', label=f'EOQ = {eoq:.2f}')
plt.title('库存成本曲线')
plt.xlabel('订货量')
plt.ylabel('总库存成本')
plt.legend()
plt.savefig('inventory_cost.png')

5.3 安全库存计算

import numpy as np
from scipy.stats import norm

# 计算安全库存
def calculate_safety_stock(lead_time, demand_std, service_level):
    """计算安全库存"""
    # 计算提前期内的需求标准差
    lead_time_demand_std = demand_std * np.sqrt(lead_time)
    # 计算服务水平对应的Z值
    z = norm.ppf(service_level)
    # 计算安全库存
    safety_stock = z * lead_time_demand_std
    return safety_stock

# 计算再订货点
def calculate_reorder_point(avg_demand, lead_time, safety_stock):
    """计算再订货点"""
    reorder_point = avg_demand * lead_time + safety_stock
    return reorder_point

# 参数设置
avg_demand = 100  # 平均日需求量
lead_time = 5  # 提前期（天）
demand_std = 20  # 日需求量标准差
service_level = 0.95  # 服务水平（95%）

# 计算安全库存
safety_stock = calculate_safety_stock(lead_time, demand_std, service_level)
print(f"安全库存: {safety_stock:.2f}")

# 计算再订货点
reorder_point = calculate_reorder_point(avg_demand, lead_time, safety_stock)
print(f"再订货点: {reorder_point:.2f}")

6.2 运输路线优化

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial import distance

# 生成配送点坐标
np.random.seed(42)
num_points = 10
depot = np.array([0, 0])
points = np.random.rand(num_points, 2) * 10

# 计算距离矩阵
dist_matrix = distance.cdist(np.vstack([depot, points]), np.vstack([depot, points]))

# 简单的最近邻算法求解TSP
def nearest_neighbor(dist_matrix, start=0):
    n = dist_matrix.shape[0]
    visited = [False] * n
    path = [start]
    visited[start] = True
    current = start
    
    for _ in range(n-1):
        min_dist = np.inf
        next_node = None
        for i in range(n):
            if not visited[i] and dist_matrix[current, i] < min_dist:
                min_dist = dist_matrix[current, i]
                next_node = i
        path.append(next_node)
        visited[next_node] = True
        current = next_node
    
    # 返回起点
    path.append(start)
    return path

# 求解TSP
path = nearest_neighbor(dist_matrix)

# 计算总距离
total_distance = 0
for i in range(len(path)-1):
    total_distance += dist_matrix[path[i], path[i+1]]

print(f"总距离: {total_distance:.2f}")
print(f"路径: {path}")

# 绘制路线
plt.figure(figsize=(10, 10))
plt.scatter(points[:, 0], points[:, 1], c='blue', label='配送点')
plt.scatter(depot[0], depot[1], c='red', s=100, label='仓库')

# 绘制路线
for i in range(len(path)-1):
    start_idx = path[i]
    end_idx = path[i+1]
    if start_idx == 0:
        start = depot
    else:
        start = points[start_idx-1]
    if end_idx == 0:
        end = depot
    else:
        end = points[end_idx-1]
    plt.plot([start[0], end[0]], [start[1], end[1]], 'k-')

plt.title('配送路线优化')
plt.xlabel('X坐标')
plt.ylabel('Y坐标')
plt.legend()
plt.savefig('route_optimization.png')
plt.show()

第7章：供应链风险分析

7.1 供应链风险识别

供应链风险是指可能影响供应链正常运作的各种因素。

  • 供应风险：供应商破产、原材料短缺、质量问题等
  • 需求风险：需求波动、预测错误、市场变化等
  • 运营风险：生产故障、物流延迟、信息系统故障等
  • 环境风险：自然灾害、政治不稳定、法律法规变化等
  • 财务风险：汇率波动、利率变化、信用风险等

7.2 风险评估方法

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 供应链风险评估
def risk_assessment():
    # 风险因素
    risks = [
        '供应商破产',
        '原材料短缺',
        '需求波动',
        '物流延迟',
        '生产故障',
        '自然灾害',
        '汇率波动',
        '信息系统故障'
    ]
    
    # 风险发生概率（1-5，5最高）
    probability = [3, 4, 4, 3, 2, 2, 3, 2]
    
    # 风险影响程度（1-5，5最高）
    impact = [5, 4, 4, 3, 3, 5, 3, 4]
    
    # 计算风险评分
    risk_score = [p * i for p, i in zip(probability, impact)]
    
    # 创建数据框
    df = pd.DataFrame({
        '风险因素': risks,
        '发生概率': probability,
        '影响程度': impact,
        '风险评分': risk_score
    })
    
    # 按风险评分排序
    df = df.sort_values('风险评分', ascending=False)
    
    print("供应链风险评估结果:")
    print(df)
    
    # 绘制风险矩阵
    plt.figure(figsize=(12, 8))
    plt.scatter(df['发生概率'], df['影响程度'], s=df['风险评分']*10, alpha=0.5)
    
    # 添加风险因素标签
    for i, row in df.iterrows():
        plt.annotate(row['风险因素'], (row['发生概率'], row['影响程度']),
                     xytext=(5, 5), textcoords='offset points')
    
    plt.title('供应链风险矩阵')
    plt.xlabel('发生概率')
    plt.ylabel('影响程度')
    plt.xlim(0, 6)
    plt.ylim(0, 6)
    plt.grid(True)
    plt.savefig('risk_matrix.png')
    plt.show()

if __name__ == '__main__':
    risk_assessment()

  • 风险转移：通过保险、合同等方式转移风险

某零售企业面临库存水平过高、库存周转率低的问题，需要通过数据分析优化库存管理。 

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 零售企业库存优化案例
def inventory_optimization_case():
    # 模拟销售数据
    dates = pd.date_range('2023-01-01', '2023-12-31', freq='D')
    np.random.seed(42)
    # 生成销售数据，包含季节性
    sales = 100 + 20 * np.sin(np.arange(len(dates)) / 30 * 2 * np.pi) + np.random.normal(0, 10, len(dates))
    sales = np.maximum(sales, 0)  # 确保销量非负
    
    df = pd.DataFrame({'date': dates, 'sales': sales})
    df['month'] = df['date'].dt.month
    
    # 计算月平均销量
    monthly_sales = df.groupby('month')['sales'].mean()
    print("月平均销量:")
    print(monthly_sales)
    
    # 计算当前库存水平（假设为月销量的2倍）
    current_inventory = monthly_sales * 2
    
    # 计算EOQ
    annual_demand = monthly_sales.sum() * 12
    ordering_cost = 100  # 每次订货成本
holding_cost = 2  # 单位年持有成本
    
    eoq = np.sqrt((2 * annual_demand * ordering_cost) / holding_cost)
    print(f"\n经济订货批量: {eoq:.2f}")
    
    # 计算最优库存水平（假设为月销量的1.2倍）
    optimal_inventory = monthly_sales * 1.2
    
    # 计算库存成本节约
    current_holding_cost = (current_inventory.sum() / 2) * holding_cost / 12
    optimal_holding_cost = (optimal_inventory.sum() / 2) * holding_cost / 12
    cost_saving = current_holding_cost - optimal_holding_cost
    print(f"\n库存成本节约: {cost_saving:.2f}")
    
    # 绘制库存水平对比
    plt.figure(figsize=(12, 6))
    plt.plot(current_inventory.index, current_inventory, label='当前库存水平')
    plt.plot(optimal_inventory.index, optimal_inventory, label='最优库存水平')
    plt.plot(monthly_sales.index, monthly_sales, label='月平均销量')
    plt.title('库存水平优化')
    plt.xlabel('月份')
    plt.ylabel('数量')
    plt.legend()
    plt.savefig('inventory_optimization_case.png')
    plt.show()

if __name__ == '__main__':
    inventory_optimization_case()

8.2 案例二：制造企业供应链风险分析

某制造企业面临供应链中断的风险，需要通过数据分析识别和评估风险，并制定缓解策略。 

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 制造企业供应链风险分析案例
def supply_chain_risk_case():
    # 供应商风险数据
    suppliers = ['供应商A', '供应商B', '供应商C', '供应商D', '供应商E']
    # 风险因素评分（1-5，5最高）
    financial_risk = [2, 3, 4, 2, 3]  # 财务风险
    quality_risk = [1, 2, 3, 2, 1]  # 质量风险
    delivery_risk = [2, 1, 3, 4, 2]  # 交付风险
    geographic_risk = [1, 3, 2, 4, 3]  # 地理风险
    
    # 创建数据框
    df = pd.DataFrame({
        '供应商': suppliers,
        '财务风险': financial_risk,
        '质量风险': quality_risk,
        '交付风险': delivery_risk,
        '地理风险': geographic_risk
    })
    
    # 计算综合风险评分
    df['综合风险'] = df[['财务风险', '质量风险', '交付风险', '地理风险']].mean(axis=1)
    
    # 按综合风险排序
    df = df.sort_values('综合风险', ascending=False)
    print("供应商风险评估结果:")
    print(df)
    
    # 绘制风险雷达图
    from math import pi
    
    categories = ['财务风险', '质量风险', '交付风险', '地理风险']
    N = len(categories)
    
    # 创建角度
    angles = [n / float(N) * 2 * pi for n in range(N)]
    angles += angles[:1]  # 闭合
    
    plt.figure(figsize=(12, 8))
    ax = plt.subplot(111, polar=True)
    
    # 绘制每个供应商的风险雷达图
    colors = ['r', 'g', 'b', 'y', 'purple']
    for i, supplier in enumerate(suppliers):
        values = df.loc[df['供应商'] == supplier, categories].values[0].tolist()
        values += values[:1]  # 闭合
        ax.plot(angles, values, 'o-', linewidth=2, label=supplier, color=colors[i])
        ax.fill(angles, values, alpha=0.1, color=colors[i])
    
    # 设置标签
    ax.set_xticks(angles[:-1])
    ax.set_xticklabels(categories)
    ax.set_ylim(0, 5)
    ax.set_title('供应商风险雷达图')
    ax.legend(loc='upper right', bbox_to_anchor=(0.1, 0.1))
    plt.savefig('supplier_risk_radar.png')
    plt.show()

if __name__ == '__main__':
    supply_chain_risk_case()

8.3 案例三：电商企业物流网络优化

某电商企业需要优化物流网络，提高配送效率，降低物流成本。 

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 电商企业物流网络优化案例
def logistics_network_optimization_case():
    # 城市坐标和需求
    cities = ['北京', '上海', '广州', '深圳', '成都', '武汉', '西安', '杭州']
    coordinates = np.array([
        [116.4, 39.9],  # 北京
        [121.4, 31.2],  # 上海
        [113.3, 23.1],  # 广州
        [114.1, 22.5],  # 深圳
        [104.1, 30.7],  # 成都
        [114.3, 30.6],  # 武汉
        [108.9, 34.3],  # 西安
        [120.2, 30.3]   # 杭州
    ])
    demand = np.array([100, 120, 90, 80, 70, 60, 50, 85])  # 各城市需求
    
    # 计算城市间距离
    from scipy.spatial import distance
    dist_matrix = distance.cdist(coordinates, coordinates)
    
    # 简单的配送中心选址（选择需求最大的前3个城市）
    top_cities = np.argsort(demand)[-3:][::-1]
    distribution_centers = [cities[i] for i in top_cities]
    print("选择的配送中心:", distribution_centers)
    
    # 分配每个城市到最近的配送中心
    assignments = []
    total_distance = 0
    for i, city in enumerate(cities):
        if i in top_cities:
            # 配送中心自己服务自己
            assignments.append((city, city, 0))
        else:
            # 找到最近的配送中心
            min_dist = np.inf
            nearest_center = None
            for j in top_cities:
                if dist_matrix[i, j] < min_dist:
                    min_dist = dist_matrix[i, j]
                    nearest_center = cities[j]
            assignments.append((city, nearest_center, min_dist))
            total_distance += min_dist * demand[i]
    
    print("\n城市分配结果:")
    for city, center, dist in assignments:
        print(f"{city} -> {center} (距离: {dist:.2f})")
    
    print(f"\n总运输距离: {total_distance:.2f}")
    
    # 绘制物流网络
    plt.figure(figsize=(12, 8))
    
    # 绘制城市
    plt.scatter(coordinates[:, 0], coordinates[:, 1], c='blue', label='城市')
    
    # 绘制配送中心
    for i in top_cities:
        plt.scatter(coordinates[i, 0], coordinates[i, 1], c='red', s=200, label='配送中心')
    
    # 绘制分配关系
    for i, (city, center, dist) in enumerate(assignments):
        if city != center:
            center_idx = cities.index(center)
            plt.plot([coordinates[i, 0], coordinates[center_idx, 0]], 
                    [coordinates[i, 1], coordinates[center_idx, 1]], 'k--')
    
    # 添加城市标签
    for i, city in enumerate(cities):
        plt.annotate(city, (coordinates[i, 0], coordinates[i, 1]),
                     xytext=(5, 5), textcoords='offset points')
    
    plt.title('物流网络优化')
    plt.xlabel('经度')
    plt.ylabel('纬度')
    plt.legend()
    plt.savefig('logistics_network.png')
    plt.show()

if __name__ == '__main__':
    logistics_network_optimization_case()
