数据合并与连接

使用merge、concat、join合并多个数据源

数据文件: orders.csv, customers.csv, products.csv

学习目标

  • 理解数据合并的概念和应用场景
  • 掌握merge方法的各种连接方式
  • 学会使用concat进行数据拼接
  • 了解join方法的使用
  • 能够处理实际的数据合并问题

1. 数据合并概述

在实际数据分析中，数据通常分散在多个表中。数据合并是将这些表按照一定的规则组合在一起的过程。

import pandas as pd

orders = pd.read_csv('orders.csv')
customers = pd.read_csv('customers.csv')
products = pd.read_csv('products.csv')

print(orders.head())
print(customers.head())

2. merge方法

merge是最常用的数据合并方法，类似于SQL的JOIN操作。

# 内连接
result = pd.merge(orders, customers, on='customer_id', how='inner')

# 左连接
result = pd.merge(orders, customers, on='customer_id', how='left')

# 右连接
result = pd.merge(orders, customers, on='customer_id', how='right')

# 外连接
result = pd.merge(orders, customers, on='customer_id', how='outer')

# 多键连接
result = pd.merge(df1, df2, on=['key1', 'key2'])

3. concat方法

concat用于沿轴方向拼接多个DataFrame。

# 纵向拼接（增加行）
result = pd.concat([df1, df2], axis=0)

# 横向拼接（增加列）
result = pd.concat([df1, df2], axis=1)

# 忽略索引
result = pd.concat([df1, df2], ignore_index=True)

# 添加标识键
result = pd.concat([df1, df2], keys=['df1', 'df2'])

4. join方法

join方法基于索引进行合并，适用于索引对齐的场景。

# 基于索引合并
result = df1.join(df2)

# 指定列名
result = df1.join(df2, on='key')

# 多表连接
result = df1.join([df2, df3])

5. 完整实战代码

import pandas as pd

orders = pd.read_csv('orders.csv')
customers = pd.read_csv('customers.csv')
products = pd.read_csv('products.csv')

order_customer = pd.merge(orders, customers, on='customer_id', how='left')
print("订单与客户合并后:")
print(order_customer.head())

full_data = pd.merge(order_customer, products, on='product_id', how='left')
print("\n完整数据:")
print(full_data.head())

customer_orders = orders.groupby('customer_id').agg(
    订单数=('order_id', 'count'),
    总金额=('amount', 'sum')
).reset_index()

customer_full = pd.merge(customers, customer_orders, on='customer_id', how='left')
print("\n客户订单统计:")
print(customer_full)

练习导航

详细说明

内连接只保留两个表中都有匹配键的行。使用how='inner'参数。

代码示例

result = pd.merge(df1, df2, on='key', how='inner')

小贴士

内连接是merge的默认方式，可以省略how参数。

详细说明

左连接保留左表所有行，右表没有匹配的用NaN填充。使用how='left'参数。

代码示例

result = pd.merge(df1, df2, on='key', how='left')

小贴士

左连接常用于保留主表所有记录的场景。

详细说明

concat用于沿轴方向拼接多个DataFrame。axis=0纵向拼接，axis=1横向拼接。

代码示例

result = pd.concat([df1, df2], axis=0)

小贴士

使用ignore_index=True可以重置索引。
