1. 聚类分析概述

聚类分析是一种无监督学习方法，用于将数据集中的样本分成若干个组（簇），使得同一组内的样本相似度较高，不同组间的样本相似度较低。

import pandas as pd

# 读取客户数据
df = pd.read_csv('user_logs.csv')
print(df.head())

2. K-means算法原理

K-means是最常用的聚类算法之一，其核心思想是：

  1. 随机选择K个中心点
  2. 将每个数据点分配到最近的中心点
  3. 重新计算每个簇的中心点
  4. 重复步骤2-3直到收敛
from sklearn.cluster import KMeans

# 创建K-means模型
kmeans = KMeans(n_clusters=3, random_state=42)

# 训练模型
kmeans.fit(df[['feature1', 'feature2']])

# 获取聚类结果
labels = kmeans.labels_
centers = kmeans.cluster_centers_

3. 选择聚类数量

使用肘部法则（Elbow Method）选择最佳的K值：

import matplotlib.pyplot as plt

# 计算不同K值的惯性
inertia = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(df[['feature1', 'feature2']])
    inertia.append(kmeans.inertia_)

# 绘制肘部曲线
plt.plot(range(1, 11), inertia, 'bo-')
plt.xlabel('Number of clusters (K)')
plt.ylabel('Inertia')
plt.title('Elbow Method for Optimal K')
plt.show()

4. 完整实战代码

import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('user_logs.csv')

# 选择特征列
features = df[['total_spent', 'visit_count', 'avg_order_value']]

# 数据标准化
scaler = StandardScaler()
scaled_features = scaler.fit_transform(features)

# 肘部法则选择K值
inertia = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(scaled_features)
    inertia.append(kmeans.inertia_)

plt.plot(range(1, 11), inertia, 'bo-')
plt.xlabel('K')
plt.ylabel('Inertia')
plt.show()

# 使用K=4进行聚类
kmeans = KMeans(n_clusters=4, random_state=42)
df['cluster'] = kmeans.fit_predict(scaled_features)

# 分析各簇的特征
cluster_analysis = df.groupby('cluster')[['total_spent', 'visit_count', 'avg_order_value']].mean()
print(cluster_analysis)

# 为每个簇命名
cluster_names = {0: '高价值客户', 1: '普通客户', 2: '新客户', 3: '流失客户'}
df['cluster_name'] = df['cluster'].map(cluster_names)

print(df['cluster_name'].value_counts())
