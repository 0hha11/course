📌 项目概述

客户聚类分析是将具有相似特征的客户分组的过程，通过聚类可以识别不同的客户群体，为每个群体制定差异化的营销策略。

  • 理解聚类分析的基本概念
  • 学习 K-Means 聚类算法
  • 掌握 RFM 客户价值分析模型
  • 学会客户画像和群体特征分析

🔧 核心代码

以下是客户聚类分析常用的代码示例：

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
import numpy as np

# 读取数据
df = pd.read_csv('customer_features.csv')

# 1. RFM 分析
def calculate_rfm(df, reference_date):
    """
    计算 RFM 指标
    R - Recency: 最近一次购买距今天数
    F - Frequency: 购买频次
    M - Monetary: 购买金额
    """
    rfm = df.groupby('customer_id').agg({
        'order_date': lambda x: (reference_date - pd.to_datetime(x.max())).days,
        'order_id': 'nunique',
        'amount': 'sum'
    }).rename(columns={
        'order_date': 'Recency',
        'order_id': 'Frequency',
        'amount': 'Monetary'
    })
    return rfm

# 2. 数据标准化
scaler = StandardScaler()
rfm_scaled = scaler.fit_transform(rfm)

# 3. K-Means 聚类
def kmeans_clustering(data, n_clusters=4):
    """执行 K-Means 聚类"""
    kmeans = KMeans(n_clusters=n_clusters, random_state=42, n_init=10)
    clusters = kmeans.fit_predict(data)
    return clusters, kmeans

# 4. 确定最佳聚类数（肘部法则）
def find_optimal_clusters(data, max_clusters=10):
    """使用肘部法则确定最佳聚类数"""
    inertias = []
    for k in range(1, max_clusters + 1):
        kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
        kmeans.fit(data)
        inertias.append(kmeans.inertia_)
    return inertias

# 5. 分析聚类结果
def analyze_clusters(rfm_data, clusters):
    """分析每个聚类的特征"""
    rfm_data['Cluster'] = clusters
    cluster_analysis = rfm_data.groupby('Cluster').agg({
        'Recency': ['mean', 'min', 'max'],
        'Frequency': ['mean', 'min', 'max'],
        'Monetary': ['mean', 'min', 'max', 'count']
    }).round(2)
    return cluster_analysis

print('客户聚类分析完成！')

💡 学习要点

  • RFM 模型：Recency(新鲜度)、Frequency(频次)、Monetary(金额)是评估客户价值的核心指标
  • 数据标准化：聚类前必须标准化，避免量纲影响结果
  • 肘部法则：帮助确定最佳聚类数量的方法
  • 聚类解释：每个聚类需要有业务含义，如"高价值客户"、"流失风险客户"

问题1：RFM 模型中的 M 代表什么？

正确答案：C

RFM 模型中：R 是 Recency(最近购买时间)，F 是 Frequency(购买频率)，M 是 Monetary(购买金额)。

问题2：K-Means 聚类前为什么要标准化数据？

正确答案：B

标准化是为了消除不同特征间的量纲差异，确保每个特征在聚类中具有同等重要性。

问题3：肘部法则用于确定什么？

正确答案：A

肘部法则通过绘制不同聚类数下的误差变化，帮助确定最佳的聚类数量。
