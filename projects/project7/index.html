时间序列分析

分析销售趋势、季节性和预测

数据文件: time_series_data.csv

学习目标

  • 理解时间序列的概念和组成要素
  • 掌握移动平均的计算方法
  • 学会分析趋势和季节性
  • 使用简单方法进行数据预测
  • 能够解读时间序列分析结果

1. 时间序列基础

时间序列是按时间顺序排列的数据序列。时间序列分析的目的是理解数据随时间变化的规律。

import pandas as pd
import numpy as np

df = pd.read_csv('time_series_data.csv')
df['date'] = pd.to_datetime(df['date'])
df = df.set_index('date')
print(df.head())

2. 移动平均

# 计算移动平均
df['MA7'] = df['sales'].rolling(window=7).mean()
df['MA30'] = df['sales'].rolling(window=30).mean()

print(df[['sales', 'MA7', 'MA30']].tail(10))

练习导航

详细说明

移动平均通过计算一定窗口内的平均值来平滑数据，消除短期波动，展示长期趋势。

代码示例 

df['MA'] = df['sales'].rolling(window=7).mean()

小贴士

窗口越大，平滑效果越明显。

详细说明

趋势是时间序列长期的变化方向。可以使用线性回归来量化趋势。

代码示例 

from sklearn.linear_model import LinearRegression
X = np.arange(len(df)).reshape(-1, 1)
model = LinearRegression()
model.fit(X, df['sales'])

小贴士

正斜率表示上升趋势，负斜率表示下降趋势。

详细说明

季节性分解将时间序列分解为趋势、季节性和残差三部分。

代码示例 

from statsmodels.tsa.seasonal import seasonal_decompose
result = seasonal_decompose(df['sales'], model='additive')

小贴士

加法模型适用于季节波动相对稳定的情况。
