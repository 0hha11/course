项目07

时间序列分析

分析销售数据的时间趋势，进行简单预测

数据文件: retail_orders.csv

学习目标

  • 理解时间序列数据的特点
  • 掌握时间序列数据的预处理方法
  • 学会绘制时间序列图表
  • 掌握移动平均等平滑方法
  • 能够进行简单的趋势预测

1. 时间序列概述

时间序列是按时间顺序排列的数据序列，常用于分析趋势、周期性和季节性。

import pandas as pd

# 读取时间序列数据
df = pd.read_csv('retail_orders.csv')
df['order_date'] = pd.to_datetime(df['order_date'])
df = df.set_index('order_date')
print(df.head())

2. 时间序列可视化

通过可视化可以直观观察时间序列的趋势和模式：

import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 绘制时间序列图
plt.figure(figsize=(12, 6))
plt.plot(df.index, df['sales'], label='销售额')
plt.title('销售趋势')
plt.xlabel('日期')
plt.ylabel('销售额')
plt.legend()
plt.show()

3. 移动平均

移动平均用于平滑时间序列数据，揭示趋势：

# 计算7日移动平均
df['ma7'] = df['sales'].rolling(window=7).mean()

# 计算30日移动平均
df['ma30'] = df['sales'].rolling(window=30).mean()

# 可视化移动平均
plt.figure(figsize=(12, 6))
plt.plot(df['sales'], label='原始数据', alpha=0.5)
plt.plot(df['ma7'], label='7日移动平均')
plt.plot(df['ma30'], label='30日移动平均')
plt.title('销售趋势与移动平均')
plt.legend()
plt.show()

4. 完整实战代码

import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 读取数据
df = pd.read_csv('retail_orders.csv')
df['order_date'] = pd.to_datetime(df['order_date'])
df = df.set_index('order_date')

# 按日期聚合
daily_sales = df['total_amount'].resample('D').sum()

# 计算移动平均
daily_sales['ma7'] = daily_sales.rolling(window=7).mean()
daily_sales['ma30'] = daily_sales.rolling(window=30).mean()

# 可视化
plt.figure(figsize=(14, 7))
plt.plot(daily_sales, label='日销售额', alpha=0.5)
plt.plot(daily_sales['ma7'], label='7日移动平均', linewidth=2)
plt.plot(daily_sales['ma30'], label='30日移动平均', linewidth=2)
plt.title('销售趋势分析')
plt.xlabel('日期')
plt.ylabel('销售额')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# 计算月度趋势
monthly_sales = df['total_amount'].resample('M').sum()
print("月度销售额:")
print(monthly_sales)

# 计算同比增长率
monthly_sales['growth_rate'] = monthly_sales.pct_change() * 100
print("\n月度增长率(%):")
print(monthly_sales['growth_rate'])
