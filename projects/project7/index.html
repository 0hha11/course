PROJECT 07

数据透视表

使用pivot_table创建多维数据分析报表

数据文件: retail_orders.csv

学习目标

  • 理解数据透视表的概念和用途
  • 掌握pivot_table方法的基本用法
  • 学会设置行、列、值和聚合函数
  • 掌握多维度透视表的创建
  • 能够进行交叉分析和数据汇总

1. 数据透视表概述

数据透视表是一种强大的数据汇总工具，可以快速对数据进行多维度分析。

import pandas as pd

df = pd.read_csv('retail_orders.csv')

print(df.head())

2. 基本透视表

使用pivot_table创建基本的透视表。

pivot = df.pivot_table(
    values='total_amount',
    index='category',
    aggfunc='sum'
)
print(pivot)

pivot_mean = df.pivot_table(
    values='total_amount',
    index='category',
    aggfunc='mean'
)
print(pivot_mean)

3. 多维度透视表

可以同时设置行和列，创建二维透视表。

pivot = df.pivot_table(
    values='total_amount',
    index='category',
    columns='region',
    aggfunc='sum'
)
print(pivot)

pivot_multi = df.pivot_table(
    values='total_amount',
    index=['category', 'product'],
    columns='region',
    aggfunc='sum'
)
print(pivot_multi)

4. 多种聚合函数

可以同时计算多种统计指标。

pivot = df.pivot_table(
    values='total_amount',
    index='category',
    aggfunc=['sum', 'mean', 'count']
)
print(pivot)

pivot = df.pivot_table(
    values=['total_amount', 'quantity'],
    index='category',
    aggfunc={'total_amount': 'sum', 'quantity': 'mean'}
)
print(pivot)

5. 完整实战代码

import pandas as pd

df = pd.read_csv('retail_orders.csv')

category_region = df.pivot_table(
    values='total_amount',
    index='category',
    columns='region',
    aggfunc='sum',
    fill_value=0,
    margins=True
)
print("按类别和地区的销售汇总:")
print(category_region)

monthly_category = df.pivot_table(
    values='total_amount',
    index='category',
    columns='month',
    aggfunc='sum'
)
print("\n按类别和月份的销售汇总:")
print(monthly_category)

category_stats = df.pivot_table(
    values='total_amount',
    index='category',
    aggfunc=['sum', 'mean', 'count', 'max', 'min']
)
print("\n各类别销售统计:")
print(category_stats)

练习导航

详细说明

使用pivot_table创建基本透视表，设置values、index和aggfunc参数。

代码示例

df.pivot_table(values='amount', index='category', aggfunc='sum')

小贴士

aggfunc默认为'mean'，如需其他聚合方式需显式指定。

详细说明

设置columns参数创建二维透视表，行和列都可以是多层次的。

代码示例

df.pivot_table(values='amount', index='category', columns='region', aggfunc='sum')

小贴士

使用fill_value参数可以填充缺失值。

详细说明

aggfunc可以接受列表或字典，同时计算多个统计量。

代码示例

df.pivot_table(values='amount', index='category', aggfunc=['sum', 'mean', 'count'])

小贴士

使用margins=True可以添加汇总行/列。
