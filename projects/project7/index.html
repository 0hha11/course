时间序列分析

进阶 45分钟 📁 time_series_sales.csv

📌 项目概述

时间序列分析是数据分析中的重要领域，用于分析随时间变化的数据。本项目将带你掌握时间序列分析的基本方法。

  • 时间序列数据预处理
  • 趋势和季节性分解
  • 移动平均和指数平滑
  • 时间序列可视化
  • 简单的预测方法

🔧 核心代码

以下是时间序列分析常用的操作：

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('time_series_sales.csv')

# 将日期列转换为datetime类型
df['date'] = pd.to_datetime(df['date'])
df = df.set_index('date')

# 1. 时间序列可视化
plt.figure(figsize=(12, 6))
plt.plot(df['sales'])
plt.title('销售趋势图')
plt.xlabel('日期')
plt.ylabel('销售额')
plt.show()

# 2. 移动平均（Moving Average）
df['MA7'] = df['sales'].rolling(window=7).mean()
df['MA30'] = df['sales'].rolling(window=30).mean()

# 3. 指数平滑（Exponential Smoothing）
df['ES'] = df['sales'].ewm(alpha=0.3).mean()

# 4. 计算增长率
df['growth_rate'] = df['sales'].pct_change() * 100

# 5. 按月份汇总
df['month'] = df.index.month
monthly_sales = df.groupby('month')['sales'].mean()

# 6. 检测异常值
Q1 = df['sales'].quantile(0.25)
Q3 = df['sales'].quantile(0.75)
IQR = Q3 - Q1
df['outlier'] = (df['sales'] < Q1 - 1.5 * IQR) | (df['sales'] > Q3 + 1.5 * IQR)

print('时间序列分析完成！')

💡 学习要点

  • 日期类型：必须将日期列转换为datetime类型，并设置为索引
  • 移动平均：用于平滑数据，去除短期波动，显示长期趋势
  • 指数平滑：对近期数据赋予更高权重，适合预测
  • 季节性：按月份/季度分析数据，发现季节性模式
  • 异常值检测：使用IQR方法识别和处理异常数据

📝 知识测试

问题1：时间序列数据中，日期列应该转换为哪种类型？

正确答案：B

时间序列分析需要将日期列转换为datetime类型，这样才能方便地进行时间索引、重采样等操作。

问题2：以下哪个方法用于计算移动平均？

正确答案：B

.rolling() 方法用于计算滚动窗口统计量，包括移动平均。.ewm() 用于指数加权，.pct_change() 用于计算变化率。

问题3：指数平滑中，alpha参数的作用是？

正确答案：A

alpha是平滑因子，取值范围0-1。alpha越大，近期数据的权重越高，对新数据的响应越快；alpha越小，平滑效果越强。
