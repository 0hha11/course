数据导出与报告

导出CSV、Excel，生成分析报告

数据文件: retail_orders.csv

学习目标

  • 掌握数据导出为CSV和Excel的方法
  • 学会设置导出参数（编码、索引等）
  • 了解如何生成数据分析报告
  • 掌握数据格式化和样式设置
  • 能够创建完整的数据分析流程

1. 导出CSV文件

使用to_csv方法将DataFrame导出为CSV文件。

import pandas as pd

df = pd.read_csv('retail_orders.csv')

df.to_csv('output.csv')

df.to_csv('output_no_index.csv', index=False)

df.to_csv('output_utf8.csv', encoding='utf-8-sig')

df.to_csv('output_selected.csv', columns=['category', 'total_amount'])

2. 导出Excel文件

使用to_excel方法将DataFrame导出为Excel文件。

import pandas as pd

df.to_excel('output.xlsx')

df.to_excel('output_no_index.xlsx', index=False)

with pd.ExcelWriter('multi_sheet.xlsx') as writer:
    df.to_excel(writer, sheet_name='原始数据')
    summary.to_excel(writer, sheet_name='汇总数据')

df.to_excel('styled.xlsx', engine='openpyxl')

3. 生成分析报告

创建完整的数据分析报告。

import pandas as pd

df = pd.read_csv('retail_orders.csv')

report = {
    '总订单数': len(df),
    '总销售额': df['total_amount'].sum(),
    '平均订单金额': df['total_amount'].mean(),
    '最大订单金额': df['total_amount'].max(),
    '最小订单金额': df['total_amount'].min()
}

report_df = pd.DataFrame(list(report.items()), columns=['指标', '值'])
report_df.to_csv('analysis_report.csv', index=False)

print("分析报告:")
print(report_df)

4. 完整实战代码

import pandas as pd

df = pd.read_csv('retail_orders.csv')

df['total_amount'] = df['price'] * df['quantity']

category_summary = df.groupby('category').agg({
    'total_amount': ['sum', 'mean', 'count']
}).round(2)

category_summary.columns = ['总销售额', '平均金额', '订单数']
category_summary.to_csv('category_summary.csv', encoding='utf-8-sig')

with pd.ExcelWriter('sales_report.xlsx', engine='openpyxl') as writer:
    df.to_excel(writer, sheet_name='原始数据', index=False)
    category_summary.to_excel(writer, sheet_name='类别汇总')

report_text = f"""
销售数据分析报告
================
总订单数: {len(df)}
总销售额: {df['total_amount'].sum():.2f}
平均订单金额: {df['total_amount'].mean():.2f}

各类别销售情况:
{category_summary.to_string()}
"""

with open('report.txt', 'w', encoding='utf-8') as f:
    f.write(report_text)

print("报告已生成！")

练习导航

详细说明

使用to_csv()方法将DataFrame导出为CSV文件，可设置编码、是否包含索引等参数。

代码示例

df.to_csv('output.csv', index=False, encoding='utf-8-sig')

小贴士

使用utf-8-sig编码可以解决中文乱码问题。

详细说明

使用to_excel()方法导出Excel文件，可以使用ExcelWriter创建多工作表文件。

代码示例

with pd.ExcelWriter('output.xlsx') as writer:
    df.to_excel(writer, sheet_name='数据')

小贴士

需要安装openpyxl库才能导出Excel文件。

详细说明

将分析结果整理成报告，可以导出为CSV、Excel或文本文件。

代码示例

report = {'总销售额': df['amount'].sum()}
pd.DataFrame([report]).to_csv('report.csv')

小贴士

报告应该包含关键指标、汇总数据和可视化图表。
