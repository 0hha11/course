特征工程

高级 60分钟 📁 customer_features.csv

📌 项目概述

特征工程是机器学习中的关键步骤，通过从原始数据中提取和构造特征，可以显著提升模型性能。本项目将介绍常用的特征工程技术。

  • 掌握特征预处理方法
  • 学习特征构造技巧
  • 理解特征选择和降维
  • 应用特征工程到实际数据

🔧 核心代码

以下是特征工程常用的代码示例：

import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler, MinMaxScaler, LabelEncoder

# 读取数据
df = pd.read_csv('customer_features.csv')

# 1. 处理缺失值
def handle_missing_values(df):
    """处理缺失值"""
    # 数值型用中位数填充
    numeric_cols = df.select_dtypes(include=['int64', 'float64']).columns
    df[numeric_cols] = df[numeric_cols].fillna(df[numeric_cols].median())
    
    # 分类型用众数填充
    categorical_cols = df.select_dtypes(include=['object']).columns
    for col in categorical_cols:
        df[col] = df[col].fillna(df[col].mode()[0])
    
    return df

# 2. 特征编码
def encode_features(df):
    """特征编码"""
    # 标签编码
    label_encoders = {}
    for col in df.select_dtypes(include=['object']).columns:
        if df[col].nunique() <= 10:  # 类别较少用标签编码
            le = LabelEncoder()
            df[col + '_encoded'] = le.fit_transform(df[col].astype(str))
            label_encoders[col] = le
        else:  # 类别较多用频次编码
            freq_map = df[col].value_counts(normalize=True)
            df[col + '_freq'] = df[col].map(freq_map)
    
    return df, label_encoders

# 3. 特征变换
def transform_features(df):
    """特征变换"""
    # 对数变换（处理偏态分布）
    for col in df.select_dtypes(include=['int64', 'float64']).columns:
        if (df[col] > 0).all():
            df[col + '_log'] = np.log1p(df[col])
    
    # 分箱/离散化
    if 'age' in df.columns:
        df['age_group'] = pd.cut(df['age'], bins=[0, 18, 30, 45, 60, 100], 
                                 labels=['<18', '18-30', '30-45', '45-60', '60+'])
    
    return df

# 4. 特征交互
def create_interactions(df):
    """创建交互特征"""
    # 数值特征之间的交互
    numeric_cols = df.select_dtypes(include=['int64', 'float64']).columns
    if len(numeric_cols) >= 2:
        df[f'{numeric_cols[0]}_x_{numeric_cols[1]}'] = df[numeric_cols[0]] * df[numeric_cols[1]]
    
    return df

# 5. 特征缩放
def scale_features(df, method='standard'):
    """特征缩放"""
    numeric_cols = df.select_dtypes(include=['int64', 'float64']).columns
    
    if method == 'standard':
        scaler = StandardScaler()
    elif method == 'minmax':
        scaler = MinMaxScaler()
    
    df_scaled = df.copy()
    df_scaled[numeric_cols] = scaler.fit_transform(df[numeric_cols])
    
    return df_scaled, scaler

print('特征工程完成！')

💡 学习要点

  • 特征预处理：缺失值处理、异常值处理、数据类型转换
  • 特征编码：独热编码、标签编码、目标编码、频次编码
  • 特征变换：对数变换、标准化、归一化、分箱
  • 特征构造：交互特征、聚合特征、时间特征、文本特征
