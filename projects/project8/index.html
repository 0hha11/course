特征工程

创建新特征，优化数据结构，为机器学习做准备

数据文件: user_logs.csv

学习目标

  • 理解特征工程的重要性
  • 掌握特征提取和转换方法
  • 学会创建衍生特征
  • 掌握特征编码技术
  • 能够进行特征选择

1. 特征工程概述

特征工程是将原始数据转换为适合机器学习模型使用的特征的过程。

import pandas as pd

df = pd.read_csv('user_logs.csv')
print(df.head())

2. 创建衍生特征

通过现有特征创建新的有价值特征：

# 创建比率特征
df['avg_order_value'] = df['total_spent'] / df['order_count']

# 创建时间特征
df['registration_date'] = pd.to_datetime(df['registration_date'])
df['days_since_registration'] = (pd.Timestamp.now() - df['registration_date']).dt.days

# 创建聚合特征
df['is_high_value'] = df['total_spent'] > 1000

# 创建交互特征
df['frequency_value'] = df['visit_count'] * df['avg_order_value']

3. 特征编码

将分类特征转换为数值特征：

# 独热编码
df_encoded = pd.get_dummies(df, columns=['category', 'region'])

# 标签编码
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df['category_encoded'] = le.fit_transform(df['category'])

# 频率编码
frequency_map = df['category'].value_counts(normalize=True)
df['category_freq'] = df['category'].map(frequency_map)

4. 完整实战代码

import pandas as pd
from sklearn.preprocessing import LabelEncoder, StandardScaler

# 读取数据
df = pd.read_csv('user_logs.csv')

# 1. 创建衍生特征
df['registration_date'] = pd.to_datetime(df['registration_date'])
df['days_since_registration'] = (pd.Timestamp.now() - df['registration_date']).dt.days
df['avg_order_value'] = df['total_spent'] / df['order_count']
df['is_high_frequency'] = df['visit_count'] > df['visit_count'].median()
df['value_score'] = df['total_spent'] * df['avg_order_value']

# 2. 处理缺失值
df['avg_order_value'].fillna(df['avg_order_value'].median(), inplace=True)

# 3. 特征编码
le = LabelEncoder()
df['region_encoded'] = le.fit_transform(df['region'])

# 4. 独热编码
df = pd.get_dummies(df, columns=['membership_type'])

# 5. 特征标准化
scaler = StandardScaler()
numeric_cols = ['total_spent', 'visit_count', 'days_since_registration']
df[numeric_cols] = scaler.fit_transform(df[numeric_cols])

# 6. 特征选择
correlation = df.corr()['target'].abs().sort_values(ascending=False)
print("特征相关性:")
print(correlation.head(10))

print("\n处理后的特征数量:", df.shape[1])
