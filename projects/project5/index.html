销售数据可视化

使用matplotlib创建销售数据图表

数据文件: sales_data.csv

学习目标

  • 掌握matplotlib的基本用法
  • 学会创建常见的图表类型（折线图、柱状图、饼图等）
  • 掌握图表的美化和定制技巧
  • 能够根据业务需求选择合适的图表类型
  • 学会创建多子图和数据对比图表

1. matplotlib基础

matplotlib是Python最流行的数据可视化库，提供了丰富的绘图功能。

import matplotlib.pyplot as plt
import pandas as pd

# 读取数据
df = pd.read_csv('sales_data.csv')

# 创建图表
plt.figure(figsize=(10, 6))
plt.plot(df['date'], df['sales'])
plt.title('销售趋势')
plt.xlabel('日期')
plt.ylabel('销售额')
plt.show()

2. 常见图表类型

# 柱状图
plt.bar(categories, values)
plt.title('类别销售对比')

plt.pie(sizes, labels=labels, autopct='%1.1f%%')
plt.title('销售占比')

3. 完整实战代码

import pandas as pd
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

df = pd.read_csv('sales_data.csv')

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

axes[0, 0].plot(df['month'], df['sales'])
axes[0, 0].set_title('月度销售趋势')
axes[0, 0].set_xlabel('月份')
axes[0, 0].set_ylabel('销售额')

axes[0, 1].bar(df['region'], df['sales'])
axes[0, 1].set_title('地区销售对比')
axes[0, 1].tick_params(axis='x', rotation=45)

axes[1, 0].pie(df['category_sales'], labels=df['category'], autopct='%1.1f%%')
axes[1, 0].set_title('产品类别占比')

axes[1, 1].scatter(df['marketing_spend'], df['sales'])
axes[1, 1].set_title('营销投入与销售关系')

plt.tight_layout()
plt.show()

练习导航

详细说明

折线图适合展示数据随时间变化的趋势。使用plt.plot()函数创建，配合title、xlabel、ylabel设置图表标题和坐标轴标签。

代码示例 

plt.plot(x, y)
plt.title('标题')
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.show()

小贴士

设置figsize可以调整图表大小。

详细说明

柱状图适合比较不同类别的数据大小。使用plt.bar()创建垂直柱状图，plt.barh()创建水平柱状图。

代码示例 

plt.bar(categories, values)
plt.barh(categories, values)  # 水平

小贴士

使用color参数可以设置柱子的颜色。

详细说明

饼图适合展示各部分占总体的比例。使用plt.pie()创建，autopct参数用于显示百分比。

代码示例 

plt.pie(sizes, labels=labels, autopct='%1.1f%%')
plt.show()
