📌 项目概述

数据可视化是数据分析的重要环节，通过图表可以直观地展示数据中的模式、趋势和异常。本项目将介绍常用的可视化工具和图表类型。

  • 学习 Matplotlib 基础绘图
  • 掌握 Seaborn 统计图表
  • 理解不同图表的适用场景
  • 学会美化和优化图表展示

🔧 核心代码

以下是数据可视化常用的代码示例：

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 设置中文字体和样式
plt.rcParams['font.sans-serif'] = ['SimHei', 'Arial Unicode MS']
plt.rcParams['axes.unicode_minus'] = False
sns.set_style('whitegrid')

# 读取数据
df = pd.read_csv('retail_orders.csv')

# 1. 折线图 - 趋势分析
def plot_line_chart(df, x_col, y_col, title):
    """绘制折线图"""
    plt.figure(figsize=(12, 6))
    plt.plot(df[x_col], df[y_col], marker='o', linewidth=2)
    plt.title(title, fontsize=14, fontweight='bold')
    plt.xlabel(x_col)
    plt.ylabel(y_col)
    plt.xticks(rotation=45)
    plt.tight_layout()
    plt.show()

# 2. 柱状图 - 对比分析
def plot_bar_chart(df, x_col, y_col, title, top_n=10):
    """绘制柱状图"""
    data = df.groupby(x_col)[y_col].sum().sort_values(ascending=False).head(top_n)
    plt.figure(figsize=(12, 6))
    data.plot(kind='bar', color='#3b82f6')
    plt.title(title, fontsize=14, fontweight='bold')
    plt.xlabel(x_col)
    plt.ylabel(y_col)
    plt.tight_layout()
    plt.show()

# 3. 直方图 - 分布分析
def plot_histogram(df, col, title, bins=30):
    """绘制直方图"""
    plt.figure(figsize=(10, 6))
    df[col].hist(bins=bins, color='#10b981', edgecolor='white')
    plt.title(title, fontsize=14, fontweight='bold')
    plt.xlabel(col)
    plt.ylabel('频数')
    plt.show()

# 4. 箱线图 - 异常值检测
def plot_boxplot(df, x_col, y_col, title):
    """绘制箱线图"""
    plt.figure(figsize=(12, 6))
    sns.boxplot(x=x_col, y=y_col, data=df)
    plt.title(title, fontsize=14, fontweight='bold')
    plt.xticks(rotation=45)
    plt.tight_layout()
    plt.show()

# 5. 热力图 - 相关性分析
def plot_heatmap(df, title):
    """绘制相关性热力图"""
    corr_matrix = df.select_dtypes(include=['int64', 'float64']).corr()
    plt.figure(figsize=(10, 8))
    sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', center=0, fmt='.2f')
    plt.title(title, fontsize=14, fontweight='bold')
    plt.tight_layout()
    plt.show()

print('数据可视化完成！')

💡 学习要点

  • 图表选择：折线图看趋势、柱状图看对比、散点图看关系、饼图看占比
  • 字体设置：中文显示需要正确配置字体，避免乱码
  • 美观原则：配色统一、标签清晰、避免过度装饰
  • 图表解读：不仅会画图，更要能解释图表中的信息
