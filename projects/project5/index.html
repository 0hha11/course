销售数据可视化

使用matplotlib绘制销售趋势图、分布图等

数据文件: retail_orders.csv

学习目标

  • 理解数据可视化的重要性
  • 掌握matplotlib的基本用法
  • 学会绘制常用图表类型
  • 掌握图表美化技巧
  • 能够根据数据选择合适的图表类型

1. 数据可视化概述

数据可视化是将数据以图形或图表的形式呈现，帮助我们更直观地理解数据模式和趋势。

import matplotlib.pyplot as plt
import pandas as pd

# 设置中文显示
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 读取数据
df = pd.read_csv('retail_orders.csv')

2. 常用图表类型

不同的数据适合不同的图表类型：

# 折线图 - 展示趋势
plt.plot(df['date'], df['sales'])
plt.title('销售趋势')
plt.xlabel('日期')
plt.ylabel('销售额')
plt.show()

# 柱状图 - 展示对比
plt.bar(df['category'], df['amount'])
plt.title('各品类销售对比')
plt.show()

# 饼图 - 展示占比
plt.pie(df['amount'], labels=df['category'], autopct='%1.1f%%')
plt.title('销售占比')
plt.show()

# 直方图 - 展示分布
plt.hist(df['amount'], bins=20)
plt.title('销售额分布')
plt.show()

3. 图表美化

通过调整样式让图表更美观：

# 设置图像大小
plt.figure(figsize=(12, 6))

# 绘制带样式的折线图
plt.plot(df['date'], df['sales'], 
         color='#ec4899', 
         marker='o', 
         linestyle='-', 
         linewidth=2,
         label='销售额')

# 添加标题和标签
plt.title('月度销售趋势', fontsize=16)
plt.xlabel('日期', fontsize=12)
plt.ylabel('销售额(元)', fontsize=12)

# 添加图例
plt.legend(fontsize=12)

# 添加网格
plt.grid(True, alpha=0.3)

# 旋转x轴标签
plt.xticks(rotation=45)

plt.tight_layout()
plt.show()

4. 完整实战代码

import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 读取数据
df = pd.read_csv('retail_orders.csv')
df['order_date'] = pd.to_datetime(df['order_date'])
df['month'] = df['order_date'].dt.month
df['total_amount'] = df['price'] * df['quantity']

# 月度销售趋势
monthly_sales = df.groupby('month')['total_amount'].sum()

plt.figure(figsize=(10, 5))
plt.plot(monthly_sales.index, monthly_sales.values, 'bo-', linewidth=2)
plt.title('月度销售趋势')
plt.xlabel('月份')
plt.ylabel('销售额')
plt.grid(True, alpha=0.3)
plt.show()

# 品类销售对比
category_sales = df.groupby('category')['total_amount'].sum()

plt.figure(figsize=(10, 5))
category_sales.plot(kind='bar', color=['#ec4899', '#f472b6', '#f9a8d4'])
plt.title('各品类销售对比')
plt.xlabel('品类')
plt.ylabel('销售额')
plt.xticks(rotation=45)
plt.show()

# 销售占比饼图
plt.figure(figsize=(8, 8))
plt.pie(category_sales.values, labels=category_sales.index, 
        autopct='%1.1f%%', colors=['#ec4899', '#f472b6', '#f9a8d4'])
plt.title('销售占比')
plt.show()
