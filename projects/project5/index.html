  • 学会移动窗口计算
  • 能够进行时间序列的基本分析

1. 日期时间处理

Pandas提供了强大的日期时间处理功能。

import pandas as pd

df = pd.read_csv('retail_orders.csv')

df['order_date'] = pd.to_datetime(df['order_date'])

df['year'] = df['order_date'].dt.year
df['month'] = df['order_date'].dt.month
df['day'] = df['order_date'].dt.day
df['weekday'] = df['order_date'].dt.weekday

print(df.head())

2. 设置时间索引

将日期列设置为索引，可以使用时间序列特有的功能。

df.set_index('order_date', inplace=True)

print(df.loc['2023-01'])

print(df.loc['2023-01':'2023-03'])

print(df['2023'])

3. 时间重采样

重采样可以将时间序列数据转换为不同的频率。

monthly = df.resample('M').sum()

weekly = df.resample('W').mean()

quarterly = df.resample('Q').sum()

daily = df.resample('D').sum()

print(monthly)

4. 移动窗口计算

移动窗口计算用于平滑数据和计算滚动统计量。

df['rolling_mean'] = df['amount'].rolling(window=7).mean()

df['rolling_sum'] = df['amount'].rolling(window=7).sum()

df['rolling_std'] = df['amount'].rolling(window=7).std()

df['expanding_mean'] = df['amount'].expanding().mean()

print(df[['amount', 'rolling_mean']].head(10))

5. 完整实战代码

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('retail_orders.csv')
df['order_date'] = pd.to_datetime(df['order_date'])
df.set_index('order_date', inplace=True)

monthly_sales = df.resample('M')['total_amount'].sum()
print("月度销售额:")
print(monthly_sales)

df['7day_avg'] = df['total_amount'].rolling(window=7).mean()

monthly_growth = monthly_sales.pct_change() * 100
print("\n月度增长率:")
print(monthly_growth)

plt.figure(figsize=(12, 6))
plt.plot(monthly_sales.index, monthly_sales.values, marker='o', color='#a855f7')
plt.title('月度销售趋势')
plt.xlabel('日期')
plt.ylabel('销售额')
plt.grid(True, alpha=0.3)
plt.show()

练习导航

详细说明

使用pd.to_datetime()将字符串转换为日期类型，然后使用dt属性提取年月日等信息。

代码示例

df['date'] = pd.to_datetime(df['date'])
df['year'] = df['date'].dt.year

小贴士

dt属性提供了很多有用的日期组件，如year、month、day、hour等。

详细说明

resample()方法用于时间重采样，可以将数据聚合到不同的时间频率。

代码示例

monthly = df.resample('M').sum()
weekly = df.resample('W').mean()

小贴士

常用频率：D(日)、W(周)、M(月末)、Q(季)、Y(年)。

详细说明

rolling()方法用于移动窗口计算，可以计算滚动平均、滚动求和等。

代码示例

df['rolling_avg'] = df['value'].rolling(window=7).mean()

小贴士

window参数指定窗口大小，可以是固定数量或时间偏移。
