1. 购物篮分析概述

购物篮分析是一种数据挖掘技术，用于发现顾客购买行为中的关联模式。它可以帮助商家了解哪些商品经常一起被购买。

import pandas as pd

# 读取购物篮数据
df = pd.read_csv('market_basket.csv')
print(df.head())

2. 关联规则的核心指标

关联规则有三个核心指标：

  • 支持度(Support)：表示项集在数据集中出现的频率
  • 置信度(Confidence)：表示在购买A的情况下购买B的概率
  • 提升度(Lift)：表示购买A对购买B的影响程度
# 计算支持度 P(A ∩ B)
support_ab = len(df[(df['A'] == 1) & (df['B'] == 1)]) / len(df)

# 计算置信度 P(B|A) = P(A ∩ B) / P(A)
confidence_ab = support_ab / (len(df[df['A'] == 1]) / len(df))

# 计算提升度 Lift = Confidence(A→B) / Support(B)
support_b = len(df[df['B'] == 1]) / len(df)
lift_ab = confidence_ab / support_b

3. 使用Apriori算法

Apriori是经典的关联规则挖掘算法，它通过逐层搜索的方式发现频繁项集。

from mlxtend.frequent_patterns import apriori, association_rules

# 准备数据（假设数据已转换为one-hot编码）
basket = df.set_index('order_id').astype(bool)

# 挖掘频繁项集
frequent_itemsets = apriori(basket, min_support=0.05, use_colnames=True)

# 生成关联规则
rules = association_rules(frequent_itemsets, metric='lift', min_threshold=1)

# 查看结果
print(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']])

4. 完整实战代码

import pandas as pd
from mlxtend.frequent_patterns import apriori, association_rules

# 读取数据
df = pd.read_csv('market_basket.csv')

# 数据预处理
basket = df.groupby(['order_id', 'product'])['quantity'].sum().unstack().fillna(0)
basket = basket.applymap(lambda x: 1 if x > 0 else 0)

# 挖掘频繁项集
frequent_itemsets = apriori(basket, min_support=0.03, use_colnames=True)
print("频繁项集:")
print(frequent_itemsets.sort_values('support', ascending=False))

# 生成关联规则
rules = association_rules(frequent_itemsets, metric='lift', min_threshold=1)

# 筛选有意义的规则
filtered_rules = rules[(rules['confidence'] > 0.5) & (rules['lift'] > 1.5)]
print("\n关联规则:")
print(filtered_rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']])

# 按提升度排序
sorted_rules = filtered_rules.sort_values('lift', ascending=False)
print("\n按提升度排序:")
print(sorted_rules.head(10))

练习导航

详细说明

支持度表示某个项集在所有交易中出现的频率。计算公式：支持度(A) = 包含A的交易数 / 总交易数。 支持度越高，说明该商品或商品组合越常见。

代码示例 

# 计算单个商品的支持度
support_a = len(df[df['A'] == 1]) / len(df)

# 计算商品组合的支持度
support_ab = len(df[(df['A'] == 1) & (df['B'] == 1)]) / len(df)

小贴士

支持度用于衡量商品或组合的普遍性。通常设置一个最低支持度阈值来筛选频繁项集。

详细说明

置信度表示在购买商品A的交易中，同时购买商品B的比例。计算公式：置信度(A→B) = 支持度(A,B) / 支持度(A)。 置信度越高，说明购买A后购买B的可能性越大。

代码示例 

# 计算置信度
confidence_ab = support_ab / support_a

# 或者直接计算
confidence_ab = len(df[(df['A'] == 1) & (df['B'] == 1)]) / len(df[df['A'] == 1])

小贴士

置信度是有方向性的，置信度(A→B)不等于置信度(B→A)。需要根据业务需求选择合适的规则方向。

详细说明

Apriori算法是经典的关联规则挖掘算法。它通过迭代的方式找出所有满足最小支持度的频繁项集， 然后基于频繁项集生成关联规则。

代码示例 

from mlxtend.frequent_patterns import apriori, association_rules

# 挖掘频繁项集
frequent = apriori(basket, min_support=0.05, use_colnames=True)

# 生成关联规则
rules = association_rules(frequent, metric='lift', min_threshold=1)

小贴士

提升度(Lift)衡量规则的有效性。Lift > 1表示正相关，Lift < 1表示负相关，Lift = 1表示无相关性。
