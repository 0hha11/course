购物篮分析

进阶 45分钟 📁 market_basket.csv

📌 项目概述

购物篮分析（Market Basket Analysis）是一种发现顾客购买模式的数据挖掘技术，通过分析顾客同时购买的商品组合，可以发现商品之间的关联关系，用于商品推荐和货架布局优化。

  • 理解关联规则挖掘概念
  • 学习支持度、置信度、提升度指标
  • 掌握 Apriori 算法原理
  • 应用购物篮分析解决实际问题

🔧 核心代码

以下是购物篮分析常用的代码示例：

import pandas as pd
from itertools import combinations

# 读取数据
df = pd.read_csv('market_basket.csv')

# 1. 数据准备
# 将数据转换为交易列表格式
transactions = df.groupby('order_id')['product'].apply(list).tolist()

# 2. 计算商品频率
product_counts = df['product'].value_counts()

# 3. 计算支持度
def calculate_support(itemset, transactions):
    """计算项集的支持度"""
    count = 0
    for transaction in transactions:
        if set(itemset).issubset(set(transaction)):
            count += 1
    return count / len(transactions)

# 4. 计算置信度
def calculate_confidence(antecedent, consequent, transactions):
    """计算规则的置信度"""
    support_both = calculate_support(antecedent + consequent, transactions)
    support_antecedent = calculate_support(antecedent, transactions)
    return support_both / support_antecedent if support_antecedent > 0 else 0

# 5. 计算提升度
def calculate_lift(antecedent, consequent, transactions):
    """计算规则的提升度"""
    confidence = calculate_confidence(antecedent, consequent, transactions)
    support_consequent = calculate_support(consequent, transactions)
    return confidence / support_consequent if support_consequent > 0 else 0

# 6. 发现频繁项集（简化版Apriori）
def find_frequent_itemsets(transactions, min_support=0.01):
    """发现频繁项集"""
    # 获取所有唯一商品
    all_products = list(set([item for sublist in transactions for item in sublist]))
    
    # 单个商品的频繁项集
    frequent_itemsets = []
    for product in all_products:
        support = calculate_support([product], transactions)
        if support >= min_support:
            frequent_itemsets.append(([product], support))
    
    return frequent_itemsets

print('购物篮分析完成！')

💡 学习要点

  • 支持度(Support)：商品组合在所有交易中出现的频率
  • 置信度(Confidence)：购买A的顾客同时购买B的概率
  • 提升度(Lift)：购买A对购买B的提升程度，>1表示正相关
  • 关联规则：形式为 A → B，表示购买A后可能购买B

📝 知识测试

问题1：在购物篮分析中，支持度衡量的是？

正确答案：A

支持度(Support)衡量的是商品组合在所有交易中出现的频率，表示商品组合的普遍性。

问题2：提升度(Lift)大于1表示？

正确答案：B

提升度(Lift)大于1表示购买A会增加购买B的概率，两者正相关；等于1表示无关；小于1表示负相关。

问题3：经典的关联规则挖掘算法是？

正确答案：B

Apriori 算法是最经典的关联规则挖掘算法，用于发现频繁项集和关联规则。
