使用Matplotlib创建折线图、柱状图、饼图等常见图表

1. Matplotlib简介

Matplotlib是Python中最常用的数据可视化库，可以创建各种静态、动态和交互式图表。

import matplotlib.pyplot as plt
import pandas as pd

plt.style.use('seaborn')

df = pd.read_csv('retail_orders.csv')

2. 折线图

折线图适合展示数据随时间变化的趋势。

import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
sales = [100, 120, 90, 150, 180]

plt.figure(figsize=(10, 6))
plt.plot(months, sales, marker='o', color='#f97316', linewidth=2)
plt.title('月度销售趋势', fontsize=16)
plt.xlabel('月份', fontsize=12)
plt.ylabel('销售额', fontsize=12)
plt.grid(True, alpha=0.3)
plt.savefig('line_chart.png', dpi=300)
plt.show()

3. 柱状图

柱状图适合比较不同类别之间的数据。

import matplotlib.pyplot as plt

categories = ['电子产品', '服装', '食品', '家居']
sales = [5000, 3000, 2000, 1500]

plt.figure(figsize=(10, 6))
plt.bar(categories, sales, color=['#f97316', '#ec4899', '#8b5cf6', '#00f5ff'])
plt.title('各类别销售额', fontsize=16)
plt.xlabel('类别', fontsize=12)
plt.ylabel('销售额', fontsize=12)
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig('bar_chart.png', dpi=300)
plt.show()

4. 饼图

饼图适合展示各部分占整体的比例。

import matplotlib.pyplot as plt

labels = ['电子产品', '服装', '食品', '家居']
sizes = [40, 25, 20, 15]
colors = ['#f97316', '#ec4899', '#8b5cf6', '#00f5ff']
explode = (0.05, 0, 0, 0)

plt.figure(figsize=(8, 8))
plt.pie(sizes, explode=explode, labels=labels, colors=colors,
        autopct='%1.1f%%', shadow=True, startangle=90)
plt.title('销售占比分布', fontsize=16)
plt.axis('equal')
plt.savefig('pie_chart.png', dpi=300)
plt.show()

5. 图表设置

可以设置图表的各种属性，包括标题、标签、图例、网格等。

import matplotlib.pyplot as plt

plt.figure(figsize=(12, 8))
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

plt.title('图表标题', fontsize=18, fontweight='bold')
plt.xlabel('X轴标签', fontsize=14)
plt.ylabel('Y轴标签', fontsize=14)

plt.legend(['数据系列1', '数据系列2'], loc='upper right')

plt.grid(True, linestyle='--', alpha=0.7)

plt.xlim(0, 100)
plt.ylim(0, 50)

plt.tight_layout()

详细说明

折线图用于展示数据随时间或其他连续变量的变化趋势。使用plt.plot()函数创建折线图。

代码示例

plt.plot(x, y, marker='o', color='orange')
plt.title('标题')
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.show()

小贴士

使用marker参数可以添加数据点标记，如marker='o'表示圆形标记。

详细说明

柱状图用于比较不同类别之间的数据。使用plt.bar()函数创建垂直柱状图。

代码示例

plt.bar(categories, values, color=['orange', 'pink'])
plt.title('标题')
plt.xticks(rotation=45)
plt.show()

小贴士

使用plt.barh()可以创建水平柱状图。

详细说明

饼图用于展示各部分占整体的比例。使用plt.pie()函数创建饼图。

代码示例

plt.pie(sizes, labels=labels, autopct='%1.1f%%')
plt.title('标题')
plt.axis('equal')
plt.show()

小贴士

autopct参数用于显示百分比，explode参数可以突出显示某一部分。
