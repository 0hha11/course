1. 数据清洗概述

数据清洗是数据分析的第一步，也是最重要的一步。它指的是对原始数据进行检查、清理和转换，以确保数据的质量和可用性。

小贴士：高质量的数据是高质量分析的基础。花时间做好数据清洗工作，可以避免后续分析中出现各种问题。

2. 处理缺失值

缺失值是数据分析中常见的问题。常见的处理方法包括：

  • 删除法：删除包含缺失值的行或列
  • 填充法：用均值、中位数、众数等填充
  • 插值法：使用线性插值等方法估计缺失值

代码示例：

import pandas as pd
import numpy as np

df = pd.read_csv('retail_orders.csv')

# 检查缺失值
print(df.isnull().sum())

# 删除包含缺失值的行
df_clean = df.dropna()

# 用均值填充数值型缺失值
df['age'].fillna(df['age'].mean(), inplace=True)

# 用众数填充类别型缺失值
df['gender'].fillna('Unknown', inplace=True)

3. 处理异常值

异常值是指与其他数据点显著不同的值。常见的检测方法包括：

  • 统计方法：使用3σ原则或IQR方法
  • 可视化方法：使用箱线图、散点图等

代码示例：

def detect_outliers(df, column):
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    outliers = df[(df[column] < lower_bound) | (df[column] > upper_bound)]
    return outliers

# 使用中位数替换异常值
median_amount = df['amount'].median()
df.loc[(df['amount'] < lower_bound) | (df['amount'] > upper_bound), 'amount'] = median_amount

4. 时间列格式化

代码示例：

df['order_date'] = pd.to_datetime(df['order_date'])

# 提取时间组件
df['year'] = df['order_date'].dt.year
df['month'] = df['order_date'].dt.month
df['day'] = df['order_date'].dt.day
df['weekday'] = df['order_date'].dt.weekday

# 格式化输出

5. 计算总价

# 计算总价
df['total_amount'] = df['price'] * df['quantity']

# 统计分析
total_sales = df['total_amount'].sum()
