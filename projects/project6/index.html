📌 项目概述

A/B测试是一种对比实验方法，用于比较两个或多个版本的效果。本项目将介绍如何设计、执行和分析A/B测试，包括统计显著性检验。

  • 理解A/B测试的基本概念
  • 学习假设检验和P值
  • 掌握显著性检验方法
  • 学会解读A/B测试结果

🔧 核心代码

以下是A/B测试分析常用的代码示例：

import pandas as pd
import numpy as np
from scipy import stats

# 读取数据
df = pd.read_csv('ab_test.csv')

# 1. 描述性统计
def ab_test_summary(df, group_col, target_col):
    """A/B测试描述性统计"""
    summary = df.groupby(group_col)[target_col].agg(['count', 'mean', 'std'])
    return summary

# 2. 双样本t检验
def t_test_ab(df, group_col, target_col, group_a='A', group_b='B'):
    """双样本t检验"""
    group_a_data = df[df[group_col] == group_a][target_col]
    group_b_data = df[df[group_col] == group_b][target_col]
    
    t_stat, p_value = stats.ttest_ind(group_a_data, group_b_data)
    
    return {
        't_statistic': t_stat,
        'p_value': p_value,
        'mean_a': group_a_data.mean(),
        'mean_b': group_b_data.mean(),
        'difference': group_b_data.mean() - group_a_data.mean(),
        'lift': (group_b_data.mean() - group_a_data.mean()) / group_a_data.mean() * 100
    }

# 3. 卡方检验（用于转化率）
def chi_square_test(df, group_col, conversion_col):
    """卡方检验"""
    contingency_table = pd.crosstab(df[group_col], df[conversion_col])
    
    chi2, p_value, dof, expected = stats.chi2_contingency(contingency_table)
    
    conversion_rates = df.groupby(group_col)[conversion_col].mean()
    
    return {
        'chi2_statistic': chi2,
        'p_value': p_value,
        'conversion_rate_a': conversion_rates.get('A', 0),
        'conversion_rate_b': conversion_rates.get('B', 0),
        'lift': (conversion_rates.get('B', 0) - conversion_rates.get('A', 0)) / conversion_rates.get('A', 0.0001) * 100
    }

# 4. 结果解释
def interpret_result(p_value, alpha=0.05):
    """解释检验结果"""
    if p_value < alpha:
        return f"统计显著 (p={p_value:.4f} < {alpha})，拒绝原假设"
    else:
        return f"统计不显著 (p={p_value:.4f} >= {alpha})，无法拒绝原假设"

print('A/B测试分析完成！')

💡 学习要点

  • 假设检验：原假设H0（无差异）vs 备择假设H1（有差异）
  • P值：P < 0.05通常认为结果统计显著
  • 检验方法：连续变量用t检验，转化率用卡方检验
  • 业务决策：不仅看统计显著性，还要看实际提升和成本

📝 知识测试

问题1：通常认为统计显著的P值阈值是多少？

正确答案：B

P < 0.05是最常用的统计显著性阈值。

问题2：比较两个组的转化率应该用什么检验？

正确答案：B

卡方检验适用于比较两个或多个组的分类变量（如转化率）。

问题3：P值小于0.05意味着什么？

正确答案：B

P < 0.05意味着我们有足够的证据拒绝原假设（两组无差异），但不能证明备择假设绝对正确。
