1. A/B测试概述

A/B测试是一种对照实验方法，通过将用户随机分成两组，对照组(A)和实验组(B)，来比较不同策略的效果。

import pandas as pd
import numpy as np

df = pd.read_csv('ab_test_data.csv')
print(df.head())

2. 统计检验

from scipy import stats

# 计算转化率
control_rate = df[df['group'] == 'A']['converted'].mean()
treatment_rate = df[df['group'] == 'B']['converted'].mean()

# T检验
t_stat, p_value = stats.ttest_ind(
    df[df['group'] == 'A']['converted'],
    df[df['group'] == 'B']['converted']
)

print(f"对照组转化率: {control_rate:.4f}")
print(f"实验组转化率: {treatment_rate:.4f}")
print(f"P值: {p_value:.4f}")

练习导航

详细说明

转化率是完成目标行为的用户占总用户的比例。计算公式：转化率 = 转化用户数 / 总用户数

代码示例 

rate = df['converted'].mean()

详细说明

T检验用于判断两组数据的均值是否存在显著差异。P值小于0.05通常被认为差异显著。

代码示例 

from scipy import stats
t_stat, p_value = stats.ttest_ind(a, b)

小贴士

P值越小，说明差异越显著。

详细说明

置信区间表示真实值可能存在的范围。95%置信区间意味着有95%的把握认为真实值在这个范围内。
