A/B测试分析

分析不同方案的效果差异，进行显著性检验

数据文件: ab_test.csv

学习目标

  • 理解A/B测试的概念和应用场景
  • 掌握假设检验的基本原理
  • 学会使用统计方法进行显著性检验
  • 掌握p值的含义和应用
  • 能够解读A/B测试结果

1. A/B测试概述

A/B测试是一种对照实验方法，用于比较两个或多个版本的效果差异。

import pandas as pd
import scipy.stats as stats

# 读取A/B测试数据
df = pd.read_csv('ab_test.csv')
print(df.head())

2. 假设检验

假设检验是判断两组数据是否存在显著差异的统计方法：

# 独立样本t检验
group_a = df[df['group'] == 'A']['conversion_rate']
group_b = df[df['group'] == 'B']['conversion_rate']

t_stat, p_value = stats.ttest_ind(group_a, group_b)
print(f"t统计量: {t_stat:.4f}")
print(f"p值: {p_value:.4f}")

# 判断结果
if p_value < 0.05:
    print("拒绝原假设，两组存在显著差异")
else:
    print("无法拒绝原假设，两组无显著差异")

3. 完整实战代码

import pandas as pd
import scipy.stats as stats
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('ab_test.csv')

# 描述性统计
print("A组描述统计:")
print(df[df['group'] == 'A']['revenue'].describe())
print("\nB组描述统计:")
print(df[df['group'] == 'B']['revenue'].describe())

# 可视化对比
plt.figure(figsize=(10, 5))
df.boxplot(column='revenue', by='group')
plt.title('A/B测试收入对比')
plt.suptitle('')
plt.show()

# t检验
group_a = df[df['group'] == 'A']['revenue']
group_b = df[df['group'] == 'B']['revenue']

t_stat, p_value = stats.ttest_ind(group_a, group_b, equal_var=False)
print(f"\nt统计量: {t_stat:.4f}")
print(f"p值: {p_value:.4f}")

# 计算效应量
cohens_d = (group_a.mean() - group_b.mean()) / ((group_a.std() + group_b.std()) / 2)
print(f"Cohen's d: {cohens_d:.4f}")

# 结论
alpha = 0.05
if p_value < alpha:
    print(f"\n结论：在显著性水平{alpha}下，拒绝原假设")
    print(f"两组收入存在显著差异（p={p_value:.4f}）")
else:
    print(f"\n结论：在显著性水平{alpha}下，无法拒绝原假设")
    print(f"两组收入无显著差异（p={p_value:.4f}）")
