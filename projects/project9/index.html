📌 项目概述

异常值检测是数据预处理中的关键环节，异常值会严重影响统计分析和机器学习模型的性能。本项目将带你掌握多种异常值检测技术。

  • IQR方法检测异常值
  • Z-score方法检测异常值
  • 箱线图可视化异常值
  • 异常值处理策略
  • 多变量异常值检测

🔧 核心代码

以下是异常值检测常用的Pandas操作：

import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('customer_features.csv')

# 1. IQR方法
def detect_outliers_iqr(df, column):
    """使用IQR方法检测异常值"""
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    outliers = df[(df[column] < lower_bound) | (df[column] > upper_bound)]
    return outliers, lower_bound, upper_bound

# 2. Z-score方法
def detect_outliers_zscore(df, column, threshold=3):
    """使用Z-score方法检测异常值"""
    z_scores = np.abs((df[column] - df[column].mean()) / df[column].std())
    outliers = df[z_scores > threshold]
    return outliers

# 3. 处理异常值
outliers, lower, upper = detect_outliers_iqr(df, 'age')
# 删除异常值
df_clean = df[(df['age'] >= lower) & (df['age'] <= upper)]
# 或者截断异常值
df['age'] = df['age'].clip(lower=lower, upper=upper)

💡 学习要点

  • IQR方法: 适合偏态分布数据，是最常用的异常值检测方法
  • Z-score方法: 适合正态分布数据，阈值通常设为3
  • 异常值处理: 根据业务场景选择删除、截断或保留
  • 可视化: 使用箱线图可以直观地识别异常值

📝 知识测试

问题1：IQR方法中，Q1和Q3分别代表什么？

正确答案：B

Q1是25%分位数，Q3是75%分位数，IQR是Q3-Q1。

问题2：Z-score方法中，常用的阈值是多少？

正确答案：C

常用的Z-score阈值是3，意味着超出均值±3倍标准差的数据被视为异常值。

问题3：以下哪种方法适合处理偏态分布数据的异常值？

正确答案：B

IQR方法基于分位数，不受极端值影响，适合偏态分布数据；Z-score方法适合正态分布数据。
