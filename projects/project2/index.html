📌 项目概述

分组聚合是数据分析中最常用的技术之一，通过 groupby 操作可以将数据按照某个或多个特征分组，然后对每个组进行聚合计算，如求和、平均值、计数等。

  • 掌握 groupby 分组操作
  • 学习常用聚合函数（sum, mean, count, max, min）
  • 多维度分组分析
  • 透视表和交叉表的使用

🔧 核心代码

以下是分组聚合分析常用的 Pandas 操作：

import pandas as pd

# 读取数据
df = pd.read_csv('retail_orders.csv')

# 1. 基本分组聚合
# 按产品类别分组，计算销售额总和
category_sales = df.groupby('category')['amount'].sum()

# 按地区分组，计算多个统计量
region_stats = df.groupby('region').agg({
    'amount': ['sum', 'mean', 'count'],
    'quantity': ['sum', 'max']
})

# 2. 多列分组
# 按地区和产品类别分组
multi_group = df.groupby(['region', 'category'])['amount'].sum().unstack()

# 3. 使用聚合函数
agg_result = df.groupby('category').agg(
    total_sales=('amount', 'sum'),
    avg_sales=('amount', 'mean'),
    order_count=('order_id', 'nunique'),
    max_quantity=('quantity', 'max')
)

# 4. 透视表
pivot_table = pd.pivot_table(
    df, 
    values='amount', 
    index='category', 
    columns='region', 
    aggfunc='sum'
)

print('分组聚合分析完成！')

💡 学习要点

  • groupby 原理：分组 → 应用 → 合并 (Split-Apply-Combine)
  • agg 方法：可以同时对不同列应用不同的聚合函数
  • 命名聚合：使用 agg 函数时可以自定义结果列名
  • 透视表：pivot_table 是交互式分析的利器

问题1：在 Pandas 中，用于分组的方法是？

正确答案：B

groupby() 是 Pandas 中用于分组的核心方法，它实现了 Split-Apply-Combine 模式。

问题2：以下哪个不是常用的聚合函数？

正确答案：C

sort() 是排序方法，不是聚合函数。常用的聚合函数有 sum, mean, count, max, min 等。

问题3：创建透视表的函数是？

正确答案：A

pivot_table() 是 Pandas 提供的创建透视表的函数，功能强大且灵活。
