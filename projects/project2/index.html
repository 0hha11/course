项目02

销售数据分组聚合

按产品、地区、时间进行分组，计算销售统计指标

数据文件: retail_orders.csv

学习目标

  • 理解分组聚合的概念和用途
  • 掌握groupby方法的基本用法
  • 学会计算常用统计指标（求和、均值、计数等）
  • 掌握多维度分组和聚合操作
  • 学会使用agg方法进行自定义聚合

1. 分组聚合概述

分组聚合是数据分析中常用的操作，它将数据按照某个或某些列进行分组，然后对每个组进行聚合计算。

import pandas as pd

df = pd.read_csv('retail_orders.csv')

# 查看数据
print(df.head())

2. 基本分组聚合

使用groupby方法进行分组，然后使用聚合函数计算统计指标。

# 按产品类别分组，计算总销售额
category_sales = df.groupby('category')['total_amount'].sum()
print(category_sales)

# 按地区分组，计算平均订单金额
region_avg = df.groupby('region')['total_amount'].mean()
print(region_avg)

# 按产品类别分组，计算订单数量
category_count = df.groupby('category')['order_id'].count()
print(category_count)

3. 多维度分组

可以按照多个列进行分组，实现更细粒度的分析。

# 按地区和产品类别分组
region_category = df.groupby(['region', 'category'])['total_amount'].sum()
print(region_category)

# 按年份和月份分组
time_group = df.groupby(['year', 'month'])['total_amount'].sum()
print(time_group)

# 重置索引，将多级索引转换为列
result = region_category.reset_index()
print(result)

4. 多个聚合函数

使用agg方法可以同时计算多个统计指标。

# 计算多个统计指标
stats = df.groupby('category')['total_amount'].agg([
    'sum', 'mean', 'max', 'min', 'count'
])
print(stats)

# 为聚合结果命名
stats_named = df.groupby('category')['total_amount'].agg(
    总销售额='sum',
    平均金额='mean',
    最大金额='max',
    订单数='count'
)
print(stats_named)

5. 完整实战代码

import pandas as pd

# 读取数据
df = pd.read_csv('retail_orders.csv')

# 计算总价
df['total_amount'] = df['price'] * df['quantity']

# 1. 按产品类别分析
category_analysis = df.groupby('category')['total_amount'].agg(
    总销售额='sum',
    平均金额='mean',
    订单数='count'
)
print("按产品类别分析:")
print(category_analysis)

# 2. 按地区分析
region_analysis = df.groupby('region')['total_amount'].agg(
    总销售额='sum',
    平均金额='mean'
)
print("\n按地区分析:")
print(region_analysis)

# 3. 多维度分析
multi_analysis = df.groupby(['region', 'category'])['total_amount'].sum()
print("\n按地区和类别分析:")
print(multi_analysis)

# 4. 按时间分析
df['order_date'] = pd.to_datetime(df['order_date'])
df['month'] = df['order_date'].dt.month
monthly_sales = df.groupby('month')['total_amount'].sum()
print("\n月度销售趋势:")
print(monthly_sales)

练习导航

详细说明

分组聚合是数据分析中最常用的操作之一。groupby()方法可以将数据按照某一列或多列进行分组， 然后对每个组应用聚合函数，如sum()、mean()、count()等。

代码示例 

# 按类别分组求和
df.groupby('category')['amount'].sum()

# 按地区分组求均值
df.groupby('region')['amount'].mean()

小贴士

groupby()返回的是一个GroupBy对象，需要再调用聚合函数才能得到结果。 可以链式调用多个聚合函数。

详细说明

多维度分组允许同时按多个列进行分组分析。通过传递一个列名列表给groupby()方法， 可以实现更细粒度的数据分析。

代码示例 

# 按地区和类别分组
df.groupby(['region', 'category'])['amount'].sum()

# 使用reset_index转换为DataFrame
result = df.groupby(['region', 'category']).sum().reset_index()

小贴士

多维度分组会产生多层索引，使用reset_index()可以将索引转换为普通列， 方便后续分析和可视化。

详细说明

agg()方法允许同时应用多个聚合函数，或者使用自定义的聚合方式。 可以传入函数名列表或字典来实现灵活的聚合操作。

代码示例 

# 多个聚合函数
df.groupby('category')['amount'].agg(['sum', 'mean', 'count'])

# 命名聚合
df.groupby('category')['amount'].agg(
    总销售额='sum',
    平均金额='mean',
    最大金额='max'
)

小贴士

使用字典形式的命名聚合可以让结果列具有更有意义的名字， 便于后续分析和报告制作。
