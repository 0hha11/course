多数据集合并

进阶 45分钟 📁 retail_orders.csv

📌 项目概述

在实际数据分析中，数据通常分散在多个数据源中。本项目将带你掌握Pandas中多种数据合并技术，实现多源数据的整合。

  • concat方法拼接数据集
  • merge方法合并数据集（SQL风格）
  • join方法基于索引合并
  • 不同连接类型（inner, left, right, outer）
  • 处理合并冲突和缺失值

🔧 核心代码

以下是多数据集合并常用的Pandas操作：

import pandas as pd

# 1. concat方法：垂直或水平拼接
df1 = pd.read_csv('retail_orders_2023.csv')
df2 = pd.read_csv('retail_orders_2024.csv')
# 垂直拼接
df_concat = pd.concat([df1, df2], axis=0, ignore_index=True)

# 2. merge方法：SQL风格的合并
orders = pd.read_csv('retail_orders.csv')
customers = pd.read_csv('customers.csv')
# 内连接
df_inner = pd.merge(orders, customers, on='customer_id', how='inner')
# 左连接
df_left = pd.merge(orders, customers, on='customer_id', how='left')
# 右连接
df_right = pd.merge(orders, customers, on='customer_id', how='right')
# 外连接
df_outer = pd.merge(orders, customers, on='customer_id', how='outer')

# 3. join方法：基于索引合并
df1.set_index('customer_id', inplace=True)
df2.set_index('customer_id', inplace=True)
df_join = df1.join(df2, how='left')

# 4. 多键合并
df_merged = pd.merge(df1, df2, on=['customer_id', 'order_date'])

💡 学习要点

  • concat vs merge: concat用于简单拼接，merge用于基于键的关联合并
  • 连接类型: inner只保留匹配项，left/right保留一侧所有数据
  • 重复列处理: 使用suffixes参数处理合并后的列名冲突
  • 索引合并: join方法适合基于索引的高效合并

📝 知识测试

问题1：以下哪种方法用于SQL风格的合并？

正确答案：B

merge方法用于SQL风格的合并，支持inner、left、right、outer等连接类型。

问题2：左连接（left join）会保留哪些数据？

正确答案：B

左连接保留左表的所有数据，右表只保留匹配的数据，不匹配的用NaN填充。

问题3：concat方法中，axis=0表示什么？

正确答案：B

axis=0表示垂直拼接（增加行），axis=1表示水平拼接（增加列）。
