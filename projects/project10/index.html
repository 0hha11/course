项目10

多数据集合并

合并多个数据集，进行综合分析

数据文件: retail_orders.csv

学习目标

  • 理解数据集合并的概念
  • 掌握merge方法进行数据合并
  • 学会使用concat方法
  • 掌握不同类型的连接（内连接、外连接等）
  • 能够处理多表关联分析

1. 数据集合并概述

在数据分析中，常常需要将多个数据集合并在一起进行综合分析。

import pandas as pd

# 读取多个数据集
orders = pd.read_csv('retail_orders.csv')
customers = pd.read_csv('customers.csv')
products = pd.read_csv('products.csv')

print("订单数据:", orders.shape)
print("客户数据:", customers.shape)
print("产品数据:", products.shape)

2. 使用merge合并

merge方法用于根据共同列合并数据集：

# 内连接 - 只保留两边都有的记录
order_customer = pd.merge(orders, customers, on='customer_id', how='inner')

# 左连接 - 保留左表所有记录
order_product = pd.merge(orders, products, on='product_id', how='left')

# 右连接 - 保留右表所有记录
full_data = pd.merge(order_customer, products, on='product_id', how='right')

# 外连接 - 保留所有记录
outer_join = pd.merge(orders, customers, on='customer_id', how='outer')

3. 使用concat拼接

concat方法用于沿着指定轴拼接数据：

# 按行拼接
df1 = pd.DataFrame({'A': [1, 2], 'B': [3, 4]})
df2 = pd.DataFrame({'A': [5, 6], 'B': [7, 8]})
result_row = pd.concat([df1, df2], axis=0)

# 按列拼接
df3 = pd.DataFrame({'C': [9, 10], 'D': [11, 12]})
result_col = pd.concat([df1, df3], axis=1)

4. 完整实战代码

import pandas as pd

# 读取数据
orders = pd.read_csv('retail_orders.csv')
customers = pd.read_csv('customers.csv')
products = pd.read_csv('products.csv')

# 查看数据结构
print("订单表列:", orders.columns.tolist())
print("客户表列:", customers.columns.tolist())
print("产品表列:", products.columns.tolist())

# 合并订单和客户数据
order_customer = pd.merge(
    orders, 
    customers, 
    left_on='customer_id', 
    right_on='customer_id',
    how='left'
)
print("\n订单+客户数据:", order_customer.shape)

# 合并产品数据
full_data = pd.merge(
    order_customer,
    products,
    left_on='product_id',
    right_on='product_id',
    how='left'
)
print("完整数据:", full_data.shape)

# 检查缺失值
print("\n缺失值统计:")
print(full_data.isnull().sum())

# 综合分析：各地区各品类销售情况
analysis = full_data.groupby(['region', 'category'])['total_amount'].agg(
    总销售额='sum',
    订单数='count',
    平均金额='mean'
).reset_index()

print("\n各地区各品类销售分析:")
print(analysis.head(10))
