第一章 数据合并基础

1.1 为什么需要数据合并

在数据分析中，数据通常分散在多个表中，需要将它们合并在一起进行分析。

  • 关系型数据：数据存储在不同表中，通过关联键连接
  • 数据整合：将多个数据源整合成一个完整的数据集
  • 数据分析：合并后才能进行全面的分析

💡 Pandas提供了强大的数据合并功能，是数据处理的核心技能之一。

第二章 merge方法

2.1 merge基础

merge方法用于根据一个或多个键将DataFrame合并在一起。

import pandas as pd

# 创建两个DataFrame
df1 = pd.DataFrame({
    'id': [1, 2, 3, 4],
    'name': ['Alice', 'Bob', 'Charlie', 'David'],
    'age': [25, 30, 35, 40]
})

df2 = pd.DataFrame({
    'id': [1, 2, 3, 5],
    'city': ['北京', '上海', '广州', '深圳'],
    'salary': [8000, 10000, 9000, 12000]
})

# 内连接（默认）
merged_inner = pd.merge(df1, df2, on='id')
print("内连接:")
print(merged_inner)

2.2 不同类型的连接

# 左连接
merged_left = pd.merge(df1, df2, on='id', how='left')
print("左连接:")
print(merged_left)

# 右连接
merged_right = pd.merge(df1, df2, on='id', how='right')
print("\n右连接:")
print(merged_right)

# 外连接
merged_outer = pd.merge(df1, df2, on='id', how='outer')
print("\n外连接:")
print(merged_outer)
第三章 concat方法

3.1 concat基础

concat方法用于沿着某个轴将多个DataFrame堆叠在一起。

# 创建两个结构相同的DataFrame
df_a = pd.DataFrame({
    'name': ['Alice', 'Bob'],
    'age': [25, 30]
})

df_b = pd.DataFrame({
    'name': ['Charlie', 'David'],
    'age': [35, 40]
})

# 纵向合并（行方向）
result = pd.concat([df_a, df_b], ignore_index=True)
print("纵向合并:")
print(result)

# 横向合并（列方向）
df_c = pd.DataFrame({
    'city': ['北京', '上海', '广州', '深圳']
})
result_h = pd.concat([result, df_c], axis=1)
print("\n横向合并:")
print(result_h)
