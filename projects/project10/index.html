多数据集合并

使用merge和concat合并数据集

数据文件: orders.csv, customers.csv

学习目标

  • 理解数据合并的概念和应用场景
  • 掌握merge方法进行表连接
  • 学会使用concat进行表拼接
  • 理解不同连接类型的区别
  • 能够处理合并过程中的数据问题

1. merge方法

merge类似于SQL中的JOIN，用于横向合并两个数据集。

# 内连接
result = pd.merge(df1, df2, on='key', how='inner')

# 左连接
result = pd.merge(df1, df2, on='key', how='left')

# 外连接
result = pd.merge(df1, df2, on='key', how='outer')

2. concat方法

# 纵向拼接
result = pd.concat([df1, df2])

# 横向拼接
result = pd.concat([df1, df2], axis=1)

练习导航

详细说明

内连接(inner join)只保留两个表中key值都存在的记录。

代码示例 

pd.merge(df1, df2, on='key', how='inner')

小贴士

内连接会丢失只在一边存在的记录。

详细说明

外连接(outer join)保留两个表中所有的记录，不存在的用NaN填充。

代码示例 

pd.merge(df1, df2, on='key', how='outer')

小贴士

外连接不会丢失任何数据。

详细说明

concat用于沿轴方向拼接DataFrame，axis=0纵向拼接，axis=1横向拼接。

代码示例 

pd.concat([df1, df2], axis=0)

小贴士

concat不要求列名一致，可以处理不同的列。
