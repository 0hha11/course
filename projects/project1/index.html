数据清洗实战

入门 30分钟 📁 retail_orders.csv

📌 项目概述

数据清洗是数据分析流程中的关键步骤，它直接影响后续分析结果的准确性。本项目将带你掌握Pandas数据清洗的核心技能。

  • 处理缺失值（NaN值）
  • 识别和删除重复数据
  • 检测和处理异常值
  • 数据类型转换
  • 数据标准化和规范化

🔧 核心代码

以下是数据清洗常用的Pandas操作：

import pandas as pd

# 读取数据
df = pd.read_csv('retail_orders.csv')

# 查看数据基本信息
print(df.info())
print(df.head())

# 1. 处理缺失值
# 删除包含缺失值的行
df_clean = df.dropna()
# 或者填充缺失值
df['age'] = df['age'].fillna(df['age'].mean())

# 2. 处理重复值
df_clean = df.drop_duplicates()

# 3. 检测异常值（使用IQR方法）
Q1 = df['price'].quantile(0.25)
Q3 = df['price'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
df_clean = df[(df['price'] >= lower_bound) & (df['price'] <= upper_bound)]

# 4. 数据类型转换
df['order_date'] = pd.to_datetime(df['order_date'])
df['amount'] = df['amount'].astype(float)

💡 学习要点

  • dropna() vs fillna(): 根据业务需求选择删除还是填充缺失值
  • 重复值检测: 使用duplicated()查看重复行，drop_duplicates()删除
  • 异常值处理: IQR方法是常用的异常值检测手段
  • 数据类型: 日期字段必须转换为datetime类型才能进行时间分析

📝 知识测试

问题1：以下哪个方法用于删除包含缺失值的行？

正确答案：B

dropna() 用于删除包含缺失值的行或列。fillna() 用于填充缺失值，drop_duplicates() 用于删除重复行，isnull() 用于检测缺失值。

问题2：以下哪个方法可以将字符串转换为日期类型？

正确答案：B

pd.to_datetime() 专门用于将字符串转换为datetime类型，是处理日期数据的首选方法。

问题3：IQR方法中，异常值的判断标准是？

正确答案：B

IQR方法中，异常值定义为小于Q1-1.5*IQR或大于Q3+1.5*IQR的值，这是统计学中常用的异常值检测标准。
