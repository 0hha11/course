1. 数据清洗概述

数据清洗是数据分析的第一步，也是最重要的一步。它指的是对原始数据进行检查、清理和转换，以确保数据的质量和可用性。

数据清洗的主要任务包括：

  • 处理缺失值（Missing Values）
  • 处理异常值（Outliers）
  • 数据格式转换
  • 数据类型转换
  • 重复数据处理

小贴士：高质量的数据是高质量分析的基础。花时间做好数据清洗工作，可以避免后续分析中出现各种问题。

2. 处理缺失值

缺失值是数据分析中常见的问题。常见的处理方法包括：

  • 删除法：删除包含缺失值的行或列
  • 填充法：用均值、中位数、众数等填充
  • 插值法：使用线性插值等方法估计缺失值

代码示例：

import pandas as pd
import numpy as np

df = pd.read_csv('retail_orders.csv')

print(df.isnull().sum())

df_clean = df.dropna()

df['age'].fillna(df['age'].mean(), inplace=True)

df['income'].fillna(df['income'].median(), inplace=True)

df['gender'].fillna('Unknown', inplace=True)

3. 处理异常值

异常值是指与其他数据点显著不同的值。常见的检测方法包括：

  • 统计方法：使用3σ原则或IQR方法
  • 可视化方法：使用箱线图、散点图等

代码示例：

import pandas as pd
import numpy as np

def detect_outliers(df, column):
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    outliers = df[(df[column] < lower_bound) | (df[column] > upper_bound)]
    return outliers

outliers = detect_outliers(df, 'amount')
print(f"检测到{len(outliers)}个异常值")

median_amount = df['amount'].median()
df.loc[(df['amount'] < lower_bound) | (df['amount'] > upper_bound), 'amount'] = median_amount

4. 时间列格式化

时间数据通常需要转换为datetime格式才能进行时间相关的分析。

代码示例：

import pandas as pd

df = pd.read_csv('retail_orders.csv')

print(df['order_date'].dtype)

df['order_date'] = pd.to_datetime(df['order_date'])

df['year'] = df['order_date'].dt.year
df['month'] = df['order_date'].dt.month
df['day'] = df['order_date'].dt.day

df['weekday'] = df['order_date'].dt.weekday

df['date_str'] = df['order_date'].dt.strftime('%Y-%m-%d')

print(df[['order_date', 'year', 'month', 'day', 'weekday']].head())

5. 计算总价

在订单数据中，通常需要计算每个订单的总价（单价 × 数量）。

代码示例：

import pandas as pd

df = pd.read_csv('retail_orders.csv')

print(df.columns)

df['total_amount'] = df['price'] * df['quantity']

print(df[['price', 'quantity', 'total_amount']].head())

total_sales = df['total_amount'].sum()
print(f"总销售额: {total_sales:.2f}")

avg_order_amount = df['total_amount'].mean()
print(f"平均订单金额: {avg_order_amount:.2f}")

max_order_amount = df['total_amount'].max()
print(f"最大订单金额: {max_order_amount:.2f}")

6. 完整实战代码

下面是一个完整的数据清洗实战代码，包含上述所有步骤： 

import pandas as pd
import numpy as np

df = pd.read_csv('retail_orders.csv')
print("原始数据形状:", df.shape)
print("原始数据前5行:")
print(df.head())

print("\n数据信息:")
print(df.info())

print("\n缺失值情况:")
print(df.isnull().sum())

df['customer_name'].fillna('Unknown', inplace=True)
df['quantity'].fillna(1, inplace=True)

Q1 = df['amount'].quantile(0.25)
Q3 = df['amount'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

median_amount = df['amount'].median()
df.loc[(df['amount'] < lower_bound) | (df['amount'] > upper_bound), 'amount'] = median_amount

df['order_date'] = pd.to_datetime(df['order_date'])
df['year'] = df['order_date'].dt.year
df['month'] = df['order_date'].dt.month

df['total_amount'] = df['price'] * df['quantity']

df.to_csv('cleaned_retail_orders.csv', index=False)

print("\n清洗完成！")
print("清洗后的数据形状:", df.shape)
print("清洗后的数据前5行:")
print(df.head())
